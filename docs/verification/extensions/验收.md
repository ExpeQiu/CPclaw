- `node --test apps/desktop/test/extensions.test.mjs`：7/7 通过。覆盖 CLI 缺失、未登录、结构化非零退出与权限不足、实际读取后就绪、并发检查合并、超时脱敏、网络不可用。
- `scripts/verify-desktop-extensions.mjs`：真实 Electron/Chromium + 模拟 CLI 桥接通过。覆盖入口高亮、权限不足反馈、原生视图位置请求、加载失败恢复、展开、关闭与 800px 窄窗口无横向溢出。
- `scripts/verify-extension-host.mjs`：真实拓展 IPC 和 WebContentsView 加载即梦公开首页通过。固定 URL、拒绝未知执行动作、第三方页面无 Node 和宿主接口、收起操作通过。使用临时 profile，无账号与生成操作。
- 原有 `scripts/verify-desktop-pane-resize.mjs` 回归通过：三个分隔线、独立宽度记忆、重载恢复、边界、双击重置、展开与窄窗口。
- 修改的主进程、preload、渲染脚本、新模块和打包脚本通过语法检查；打包清单包含新宿主与服务模块。本轮未重新打包完整安装包。

## 完成边界

本轮只接入固定即梦应用，CLI 路径使用用户 `~/.local/bin`，无通用 shell 执行入口。状态检查设置超时和输出上限；前端只收到脱敏状态，不接收原始账号或画布列表。

原生页面使用独立持久 partition，不接入 CPclaw preload；导航限于即梦同源，外部跳转和弹窗暂不开放，因此跨站登录可能无法完成。检查成功仅代表 CLI 只读能力可用，不代表网页已登录。

未实现：从 AI 对话执行创作命令、安装与登录向导、原生画布 URL 关联、生成参数面板、结果下载卡片、应用/文档标签栏及完整任务恢复。应用与文档目前通过快捷入口切换。此增量不等于完整功能需求全部交付。
