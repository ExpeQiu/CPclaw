# 自诊断图片恢复验收

日期：2026-10-28。

## 已完成

- 根据持久化提交/资源身份识别待查询、生成成功、交付成功、明确失败与未知状态。
- 自诊断可在平台断网时恢复已有本机图片；恢复回执、图片入口与说明写回原消息，保留原始执行错误。
- 对已提交但终态未知或缺少下载的任务提供受限续接，仅查询原提交、核实资源、下载已有图片；不创建节点、不调用生成、不重新扣费。
- 下载与预览状态分离；成功下载的路径、大小和哈希不会因预览异常而丢失。
- 原生解码生成最长边2048像素的缩略预览，保留原图并提供打开入口；支持原文件不超过64 MiB。
- 节点 ID 按10位 Crockford Base32规范生成；诊断细分节点、CLI参数、终端参数、网关、步骤上限和交付故障。
- 无修复时明确记录 `repairState=none, verified=0`；原始历史故障与当前成果状态分开展示。
- 账号/聊天目录及真实路径校验，拒绝目录外软链接；保留文件哈希校验。
- 修复重启竞态：旧工作进程退出或返回消息时，不再清除新进程的请求与状态。
- 打包清单包含新增的状态分析和文件校验模块。

## 使用与边界

部署此源码后，在有生图执行记录的当前对话点击「自诊断」，本机已有成果会自动恢复。缺少终态或下载时点击「续接已有任务并恢复图片」，按原提交查询；仍在处理中会保持待查询，允许稍后再次诊断，不无界轮询。

本轮覆盖已有身份的图片任务。任意历史消息选择、视频/音频交付、自动重新生成及服务端网关自身修复仍不在本轮范围；图片交付可用不等于用户已经接受画面质量，也不代表其他业务目标完成。
