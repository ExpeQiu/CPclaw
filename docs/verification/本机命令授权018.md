# 本机命令授权优化 0.0.18

日期：2026-10-24。状态：源码、测试及本机安装完成。

## 完成范围

新增宿主原生确认弹窗，展示用途、当前电脑、实际可执行程序及参数、真实工作目录。默认拒绝按钮，Escape 与关闭按拒绝处理；默认仅本次，勾选后只允许当前账号/当前对话中完全相同的即梦只读检查。未选定已登录对话时不提供对话授权。

授权保存在主进程内存。绑定实际程序内容哈希、命令参数、工作目录与上下文；变更后重问。拒绝、无效来源窗口、前端伪造 approved 字段均不能启动程序。会话切换、账号变化、窗口关闭/重载、重启与撤销使授权失效；检查中的撤销通过 AbortSignal 中断进程和后续步骤。

覆盖两个本地入口：拓展即梦检查、技能市场 CLI 版本检测。后者原来在工作进程直接执行，现改为工作进程只返回执行计划，由本机主进程弹窗后执行，且仅允许本次。原 MCP 网络握手不变。没有加入第二套 Agent 循环或开放通用 shell。
