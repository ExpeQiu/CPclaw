# 智能文档与导航 0.0.6

日期：2026-10-23。

## 本次实现

- 移除生成模式开关及关键词意图判断，接入原生 `deliver_document` 工具，模型根据需求和当前文档选择直接回答或文档交付。文件名、正文、源文档ID均通过结构校验，修改目标必须属于当前账号/聊天快照，完成后才落盘。
- 文档工具请求启用任务推理与独立 reasoning 字段；推理内容不显示或保存为正文。初版关闭推理时真实短提纲可能只返回聊天文本，已在真实链路复现并修正，未用关键词兜底。
- 文档工作区左侧为标签、路径/操作、正文/源文，右侧为文件版本树与标题大纲；支持筛选、跳转、独立滚动、展开及关闭恢复聊天。
- 最左新增44px窄快捷栏，接入工作台、新建聊天、文档、技能市场、个人资料、设置和账号，包含名称提示、状态高亮与键盘导航。
