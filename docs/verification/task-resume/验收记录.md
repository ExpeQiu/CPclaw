## 实现

- 对来源不明确的项目架构/源码分析先询问，避免擅自搜索主目录或选择同名仓库。
- 保存原输入、项目、文档上下文及已确定路线。重试不能改变路线、项目或已选服务配置。
- 内核持久化接收回执到达即保存检查点；失败后恢复同一会话。接收不确定或工具结果不确定时，不盲目重发。
- 相同任务内，用规范化SHA-256指纹复用已成功的相同工具调用回执；不跨任务复用。语义相同但参数不同的操作不能仅凭该指纹去重。
- 文档分段暂存，安全识别的截断正文保留为草稿；完成后合并发布。草稿跨重启保留，名称和修订目标固定。
- 对指定临时HTTP错误最多3次模型尝试，遵循Retry-After和超时预算；HTTP200之后的流中断不重放。
- 自然语言“继续原任务”等明确续接语句与重试按钮使用同一恢复路径，界面不多插临时用户消息。
