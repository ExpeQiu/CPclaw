# 即梦 CLI 连接修复 0.0.17

日期：2026-10-24。

## 根因与修复

即梦 CLI 的非零退出响应会把 JSON 错误写到 stderr。原 extension-service 只解析 stdout；实际 canvas ls 返回退出码 11、stdout 为空、stderr 为结构化 oauth_scope_insufficient，被误报为「CLI 检查失败或超时」。

修复为依次解析 stdout/stderr 中的结构化协议；不把原始 stderr 或凭据转发到界面。进程被超时终止时不将残留成功响应当作已完成。

## 认证与实际连接

按服务端建议，从官方地址重新安装 CLI 和 Skill，CLI 由 1.0.1 更新到 1.1.1（commit a5ca7c8）。旧二进制及 Skill 备份在 /tmp/cpclaw-jimeng-before-repair，未备份或导出凭据。

用同一 default profile 重新发起官方授权，用户在官方页面完成确认；auth wait 返回 logged_in。随后使用热修复服务实际执行版本检查、认证检查和 canvas ls，结果为 ready：CLI 已登录，画布读取检查通过。不记录授权码、账号信息或画布内容，不提交生成任务。
