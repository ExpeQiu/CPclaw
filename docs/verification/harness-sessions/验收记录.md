# 聊天与 Harness 会话绑定验收

日期：2026-11-05。范围为 CPclaw 源码、适配器、本机 deepseek-harness SDK，以及本轮打包安装的 0.0.38；未执行正式签名安装包或真实模型验收。

## 实现规则

- 新聊天分配唯一内核会话编号，持久保存在 `chat_harness_sessions`；原有聊天首次使用内核时补建绑定。
- 实际调用内核时使用固定编号和 `harness-sessions/<会话编号>` 独立目录。每轮仍关闭进程，后续通过持久化事件恢复同一会话。
- 普通聊天沿用模型网关；进入内核时补入尚未传入的成功问答与当前检索资料，避免重复追加已有内核历史。
- 不同聊天隔离消息、执行记录和内核上下文。同项目可共享文件目录、成果和资源；关联同一知识库的聊天可以读取共同资料，来源选择与操作权限仍按聊天管理。
- 移动项目归属不重置会话，既有历史保留。恢复失败时明确失败，不静默替换为空会话。
