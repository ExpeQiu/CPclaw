- 登录失败按账号/来源地址限流；返回 429 与 Retry-After。
- 平台恢复及桌面宿主源码的支持上限由 schema 3 对齐到当前 schema 4，先前恢复回归失败已修复。

## 边界

- 当前是单节点业务管理基线，沿用 admin/employee 两类角色，不引入 SSO、域名、HTTPS 或多副本限流；本轮不宣称完成所有企业生产或认证要求。
- 个人文件、聊天历史、本地项目与 Wiki、目录驱动、Computer Use、本机凭据及本机授权仍由桌面管理。
- 组织连接器禁用影响云端登记的自定义 CLI/MCP 连接器目录，不终止已在本机运行的进程；内置即梦、飞书 CLI 等不属于该登记表。
- 企业学习与发布 Wiki 是已有领域服务入口，当前桌面没有自动上传学习候选或发布 Wiki 的用户流程。
- IM 与远程设备仅展示已有领域登记元数据；桌面消息渠道仍属预留，不表示真实飞书/企微消息已接入。
- 增额申请沿用既有自动批准规则；本轮不擅自切换成手工审批。
- 备份恢复兼容与撤权回放已验证，生产灾备仍需同时保全数据库、权威台账、上传文件与运行配置，并停服执行恢复。
