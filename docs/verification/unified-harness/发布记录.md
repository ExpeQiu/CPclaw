## 回滚

应用回滚前先退出新应用并保存当前数据副本，再恢复备份中的旧应用。0.0.42 已允许单轮多文档，旧版不能等价使用新的文档表约束；如确需恢复旧数据库，必须先核对升级后是否有新聊天，不能直接覆盖。

云端可将回滚镜像重新标记为 `cpclaw-platform:current`，恢复对应源码后在原 Compose 目录使用 `up -d --no-build --force-recreate`。本轮无平台 schema 迁移，无须为了代码回滚覆盖线上新增数据；只有数据库损坏等明确原因才考虑一致快照恢复。
