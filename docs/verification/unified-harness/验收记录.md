源码验收日期：2026-11-05。后续用户已授权打包、替换本机与部署云端，最新发行状态另见 [发布记录](发布记录.md)；以下未发布描述记录源码验收时状态。

范围：桌面源码、配套模型/平台管道、中文指南及回归入口。未生成新 DMG、未替换本机 CPclaw 应用、未部署云端。工作区原有其他改动保留；本次未提交 Git。

## 实现结果

- 每个新聊天保存一个唯一 Harness 会话映射；普通问答、澄清、自然语言“继续”、工具执行与文档交付进入同一会话。SDK 进程可回收，持久会话继续恢复。
- 桌面不调用独立 `/v1/chat/stream`，不筛选成功历史重建上下文、不按关键词决定研究或执行、不注入业务收尾指令、不另开模型续写文档。原文与明确分隔的输入引用元数据投递，模型正文事件持续转发并持久化。
- 通过类型化工具提供文件、终端、CLI、MCP、浏览器、知识资源、文档交付和结构化结果。目录及正文由内核按需读取；大结果完整保存并按偏移分页，保留稳定引用。
- 项目、知识库、技能按显式关联提供。平台知识每次读取重新检查 ACL；技能与外部服务调用重新核对当前有效版本/配置。不同聊天的历史、会话与执行回执独立。
- 内核提交文档分段，宿主按段序、目标版本和哈希保存；支持同轮多份文档。草稿跨进程重启保留，旧数据库唯一约束迁移保留原版本。原文字节不由宿主去围栏或改写。
- Wiki、Skill 草稿、创作过程文档、授权学习和诊断解释统一经内核。学习在读取材料和提交前重新检查授权，提交过程串行；人工审核及既有发布权限不变。
- 自诊断保留结构化健康检查及已有媒体文件的维护恢复；恢复成果单独显示，不补写历史答案，不从局部交付推断整个任务完成。「由内核解释诊断」使用当前聊天的同一会话和原始执行证据。
- 已接收或受理不明的输入禁止整轮重投；未确认的工具结果保留 unknown，同一稳定调用 ID 不重复执行。相同参数的新调用不擅自复用旧结果。SDK/网络/外部服务不具备普遍的 exactly-once 保证，未知副作用必须先核实。
- 旧聊天通过显式「关联原历史并继续」暴露只读记录与旧草稿，不摘要导入、不自动重放。旧报告执行入口改为只读；平台旧模型接口和旧适配插件暂留给旧消费者，新桌面不走这些路径。

旧历史迁移用例另验证了 4212 字旧文档草稿完整可读。新增用例验证了运行中撤销学习授权后材料读取被拒绝且不向学习发布接口发送候选，以及旧文档表迁移后原文件/哈希不变且单轮可交付两份新文档。

供应商响应均为确定性测试夹具。实际 SDK 与 Electron 运行不等同真实模型在开放任务上的理解、工具选择或内容质量验收。

## 可复核入口

- `apps/desktop/chat-service.mjs`：唯一桌面运行入口、会话、资源、显式作业、诊断与迁移。
- `apps/desktop/harness-tools.mjs`：工具 schema、稳定调用回执、分页与原生分段文档。
- `packages/harness-adapter/src/pipeline-plugin.mjs`：SDK 类型化工具插件。
- `packages/harness-adapter/src/index.ts`：原始输入、供应商流、SDK 生命周期与结束原因。
- `packages/model-gateway/src/index.ts`、`packages/platform/src/http.ts`：新协议透明代理及认证、计量和诊断。
- `apps/desktop/test/unified-harness.test.mjs`、`apps/desktop/test/task-resume.test.mjs`、平台集成测试与两个 unified 验证脚本。
