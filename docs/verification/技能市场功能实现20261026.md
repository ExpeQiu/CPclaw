# 企业技能市场功能实现与验证

日期：2026-10-26。本记录覆盖源码开发、隔离验证与使用文档；随后已按用户授权完成本机/云端同步更新，见 [0.0.21 发布记录](技能市场发布021.md)。正式目录未自动写入内容。

## 实现范围

- 统一技能领域：稳定技能身份、不可变版本、固定提交修订，旧市场及企业 API 经同一服务操作发布与审核表；保留旧 ID 和聊天引用，迁移不按标题合并。
- 市场展示：四个入口、工作分类、别名搜索、排序、分页、独立筛选条件、空态、结构化详情、样例、版本与正文/依赖差异、个人副本。
- 本机生命周期：多文件制品、摘要与文件校验、不可变目录、准备与激活分离、原子指针、真实本机状态、同请求幂等、取消、失败与中断状态。
- 任务使用：新建或当前对话选用，必填输入，项目材料选择，固定运行快照，解除绑定，问答/文档/服务链路共用方法；沿用当前对话权限。
- 创作共享：分区编辑、并发修订冲突、固定草稿试用、检查记录、个人快照与审核分开、撤销提交、退回重提、新版本维护。
- 治理：常规下架与紧急停用分开，后续工具调用前复核有效性；更新/审核通知、问题反馈、精选排序。
- 内容：六个官方方法内容包；管理员明确导入草稿后试用和发布。两个专家草稿锁定成员版本，并按本次选择只加载对应任务方法。

## 已知边界

个人草稿仍保存在平台，管理员可见，未擅自更改组织可见规则。选定知识资料生成草稿、通用 OAuth、自动 references 加载、Office 原生处理器和额外开放市场不在本轮实现中。安装制品保留以支持历史运行；未新增自动磁盘垃圾回收。

结构检查只检验声明的章节/入口及执行状态，不证明所有业务事实正确；模型/服务成本使用既有通道。正式上架前，维护者需补真实目标环境中的正常、异常和恢复案例。
