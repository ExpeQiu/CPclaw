# 自然对话与应用服务 0.0.19 验收

2026-10-24。最终按用户确认采用自然对话，不展示对话/CLI 模式开关。

## 实现

- 普通聊天与文档交付保持原入口。模型收到可用服务目录，通过 request_service 请求实际操作，明确服务时直接转入 Harness，有歧义时弹窗选择。
- Harness 仍是唯一工具循环；service_action 连接本机 CLI 或 MCP HTTP 服务。平台只转发模型请求与结算，不在云端执行用户 CLI。
- 工作进程与主进程双向 RPC 将本机授权与执行隔离到宿主。选择服务不等于授权；拒绝、取消、切换会话/账号会停止后续操作。
- 即梦从实际 schema/model 发现能力，先保存再报价，积分批准由本机弹窗控制，token 不进入模型。提交与保存身份在副作用前记录，超时错误返回恢复身份。
- 右侧操作面板展示逐步回执、官方画布入口和经过格式/大小/SHA256 校验的已下载图片；服务与执行记录按账号/聊天隔离。
- 测试中的工单系统与 CLI 夹具均位于隔离数据目录，不写入正式服务目录。
