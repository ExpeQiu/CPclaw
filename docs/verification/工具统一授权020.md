# 工具统一授权验收

2026-10-25。授权范围统一覆盖已选服务的本机终端指令、CLI 操作与 MCP 工具调用。

- 默认“本次任务”：首次确认后，同一任务的能力发现、读取、写入、保存、查询、生成与下载共用授权。新任务重新确认。
- “Auto”：当前账号、当前对话、同一服务的后续任务自动执行。切换账号或对话、撤销授权、退出应用后失效，不持久化授权。
- “仅当前操作”：保留逐次确认供用户选择。
- 授权绑定服务地址、本机程序真实路径和内容指纹，不扩展到其他服务或被替换的程序。CLI 任务授权包含该程序的后续参数变化，授权框明确展示这一范围。
- 即梦积分只是此授权中的可选额度限制：按实时权威报价累计预留，额度内不再弹窗；超额须明确提高累计上限。提交结果不确定时不释放预留额度，不自动重跑。
- 操作面板显示任务或 Auto 状态、积分累计预留值，并提供“撤销工具授权”。拒绝、Escape、停止或上下文变化均不得执行待批准指令。
- 登录服务时所需的官方账号认证仍由服务提供方处理，不等同于 CPclaw 的执行授权。
