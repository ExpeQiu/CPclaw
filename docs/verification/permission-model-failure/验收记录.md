# 权限失效停止与模型连接诊断

日期：2026-11-06。针对聊天 5b6ab08b 的 0.0.43 新请求：首段文件写入成功，随后两次权限失效回执未停止整轮，最终模型 fetch 失败只展示通用错误。

## 修复

- 任务权限版本变化返回独立 `PERMISSION_CHANGED`，单次操作拒绝仍为 `DENIED`。无论执行桥返回结构化错误或抛出该错误，宿主先保存回执，再中止当前 Harness 运行。后续工具/模型不能继续换通道执行；显示“权限已改变，本轮已停止”，执行状态为 error，非用户主动取消。新输入在当前权限下建立新运行，不重投已接收输入。
- 模型连接和读流异常分别记录 `MODEL_CONNECTION_FAILED` / `MODEL_STREAM_INCOMPLETE`；超时保留 `MODEL_STREAM_TIMEOUT`。持久诊断关联 loop 调用 ID、阶段及允许列表内的 Node/Undici/TLS 原因码。
- 不保留 cause 原文、URL、headers、凭证或供应商错误正文。诊断清洗保留允许的 transportCode，拒绝任意值；界面说明已有文件和回执保留。取消原因优先于网络错误，不将权限失效伪装成网络故障。

## 验证

权限停止用例修改前失败，修改后通过。验证首段原文件与已收到正文保留，整轮信号失效后 write_file 被拒绝，当前输入不整轮重放；返回错误与抛出错误两种执行桥均覆盖。

适配器测试通过实际本地 HTTP 网关，使用 SDK 夹具与受控 fetch 注入，分别模拟连接前 ECONNREFUSED、读流 UND_ERR_SOCKET，验证错误分类、阶段、调用标识及不泄漏原始错误。它不证明复现了原现场具体网络根因。
