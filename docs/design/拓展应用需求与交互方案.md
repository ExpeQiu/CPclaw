# 拓展应用需求与交互方案

日期：2026-10-24。状态：功能规划，尚未实现；即梦接入能力待验证。

## 1. 目标与已确认边界

用户在 CPclaw 左侧对话驱动外部应用，通过 CLI 执行操作，在右侧应用工作区查看操作页面和结果。右侧优先显示应用原生网页或本地 Web 页面，也接受 CPclaw 根据 CLI 能力生成的操作面板。

首期完成一个应用的闭环：发现/安装 → 可用性检查 → 登录授权 → 打开工作区 → 对话执行 → 查看并保存结果 → 继续修改。以即梦画布为首个接入候选。

本文件交付需求、交互、接入边界和验收用例，不代表已执行安装或通过真实接入验收。

## 2. 用户场景

### 2.1 通过对话安装应用

用户提供的典型请求：

> 请帮我安装即梦画布 CLI & Skill，根据当前操作系统和终端执行对应命令。安装完成后，进一步阅读 CLI Skill，并引导我完成可用性验证和登录授权。

用户提供的安装入口示例（仅记录，不代表已核验脚本内容或当前支持范围）：

| 环境 | 示例命令 |
|---|---|
| macOS / Linux | `curl -fsSL https://jimeng.jianying.com/canvas-cli/install.sh \| bash` |
| Windows PowerShell | `irm https://jimeng.jianying.com/canvas-cli/install.ps1 \| iex` |
| Windows CMD | `curl.exe -fsSLO https://jimeng.jianying.com/canvas-cli/install.bat && install.bat` |

流程：

1. 根据本地宿主事实识别操作系统与执行终端，不凭对话语言推断。先检查已有 CLI、版本和 Skill，避免重复安装或自动覆盖已有版本。
2. 展示应用名称、安装来源与执行阶段。安装能力受平台发布与授权约束，不能把用户粘贴的任意脚本直接注册成获准拓展。
3. 对已获准的应用安装入口执行对应安装；不匹配当前环境的命令不执行。用户已有明确安装授权时不重复询问相同授权。
4. 安装进程退出后，重新定位 CLI，读取版本、帮助及能力描述；验证 Skill 是否实际安装、能否读取、是否与版本兼容。退出码为零不等于全部就绪。
5. 读取对应 Skill 作为操作说明，发现当前 CLI 真实命令；Skill 文本不能自行扩大宿主权限。
6. 检查登录状态，需要时展示授权入口。用户在授权页面完成登录，CPclaw 回查 CLI 的身份状态；关闭页面不视为登录成功。
7. 展示检查结果：CLI、Skill、账号与应用页面分别标记状态。满足条件后显示「打开应用」。

若应用尚未获准安装，明确显示「等待管理员开放」；可继续查看说明，不通过通用终端绕过限制。这延续 ADR-001 的已发布资源与权限边界。

### 2.2 对话驱动生成

用户启动即梦后输入「生成一张秋日露营海报，横版」。当前对话明确绑定即梦，AI 根据实时能力选择参数，调用 CLI。对话显示进度和结果卡片，右侧展示对应画布或操作面板。后续「把背景改为黄昏」关联已选任务和素材；目标不明确时先让用户选择。

涉及服务端积分批准时显示实际报价并等待决定；安装和登录授权不包含无限额生成授权。

### 2.3 手动操作后继续对话

用户在原生页面调整画布后要求 AI 继续修改。执行前重新读取目标应用状态，不能只使用聊天中旧状态。页面若不支持选中对象同步，使用 CLI 返回的对象列表让用户选择，不声称已获得页面当前选区。

## 3. 页面与交互

### 3.1 入口与布局

最左快捷栏截图红框位置新增「拓展」，使用图标和悬停名称。打开拓展列表时保留当前对话。列表项显示应用名、说明、状态和主操作。

```text
快捷栏 | 聊天列表 | 当前对话                    | 应用工作区
       |          | 当前应用：即梦              | 即梦 · 已连接
 拓展  |          | 用户指令 / 进度 / 结果卡片  | 原生页面 或 CLI 面板
       |          | 输入框                      | 刷新 / 展开 / 关闭
```

右侧工作区沿用现有面板的宽度记忆、拖动调整和展开方式。应用与文档通过标签切换，共用右侧区域，不新增第三个内容分栏。切换标签不重启任务。窄窗口采用覆盖视图，提供「返回对话」，恢复输入焦点。

### 3.2 应用列表状态

| 状态 | 主操作 | 反馈 |
|---|---|---|
| 未安装 | 安装 | 说明来源、所需组件 |
| 安装中 | 查看进度 | 分阶段展示，不重复启动安装 |
| 检查失败 | 查看原因 / 重试检查 | 分别指出 CLI、Skill 或版本问题 |
| 待登录 | 登录授权 | 展示授权入口和等待状态 |
| 就绪 | 启动 | 打开工作区并绑定当前对话 |
| 连接异常 | 重新连接 | 保留原任务和结果 |
| 未获准 | 查看说明 | 明确管理员开放路径 |

首次点击安装只表示安装，登录完成后由用户点击「启动」或按其明确的连续指令继续。已安装但未登录仍允许展示登录页。

### 3.3 右侧工作区

- 原生页面：使用应用返回或已核验的页面地址，不拼造画布 URL。支持登录、刷新、展开和关闭；本地 Web 页面也属于原生页面候选，任意桌面原生窗口嵌入不在首期范围。
- CLI 面板：由适配器定义受支持的操作、参数和结果组件。展示必要的模型、比例、素材、提交按钮及任务列表，不把完整命令行参数直接铺给用户。
- 同时支持两种视图时提供「原生页面 / 操作面板」切换，共用任务身份。默认模式在应用接入验证后配置。
- 原生页面加载失败时说明原因；存在 CLI 面板时提供切换按钮，不静默替换。
- 关闭面板仅收起视图，任务继续。停止操作使用独立按钮；不支持远端取消时如实显示「已停止等待，应用任务可能仍在运行」。

### 3.4 左侧执行与结果

输入框上方显示当前应用。首期一个对话关联一个应用，切换应用通过明确操作完成；运行期间禁止将同一对话切换到其他应用，查看其他内容不受影响。

任务卡片显示：准备中 → 执行中 → 成功 / 失败 / 已取消 / 状态待确认。等待用户授权是独立等待状态。卡片支持查看原因、查询原任务、在应用中查看和可用时取消。

结果卡片包含预览、产物名称、保存、继续修改、在应用中查看。只有获得可读取的实际产物才能宣告交付。在线结果可查看但本地保存失败时分别报告，不整体显示已保存。

## 4. 接入与执行约定

沿用现有 Harness 编排、本地宿主执行和状态投影，不增加第二套 Agent 循环。

```text
左侧对话 → Harness → 已获准应用适配器 → CLI → 应用
                         ↓
                 本地任务状态与结果
                         ↓
                 对话卡片 / 右侧面板
```

最小适配器契约：

| 能力 | 职责 |
|---|---|
| 应用描述 | 标识、名称、CLI 入口、安装来源、Skill 位置、支持的视图 |
| 环境检查 | 已安装状态、版本、兼容性、当前能力 |
| 安装与认证 | 执行获准安装流程、返回授权入口、查询登录状态 |
| 打开页面 | 返回原生页面地址及关联的画布/项目身份 |
| 操作描述 | 声明允许的操作、参数及结果类型，供工具和面板共用 |
| 任务执行 | 提交、查询、可选取消、收集并验证产物 |

宿主生成本地任务 ID，保存会话 ID、应用 ID、公开的远端操作 ID、画布/对象 ID 和产物路径。凭证由应用认证机制或宿主凭证存储管理，不写入聊天、任务日志或普通任务记录。

CLI 与页面共享账号不能直接假定；分别检查，账号不一致时暂停相关操作并提示。页面嵌入使用隔离的应用会话，不向第三方页面暴露 CPclaw Node 能力或通用宿主桥接；外部导航和弹窗交由明确的登录/打开流程处理。

手动面板与 AI 调用走同一执行入口。同一应用上下文的写操作按序执行，执行前读取最新状态。原生页面手动修改的冲突，优先利用版本检查；无此能力时声明同步限制并重新读取，不能承诺完整实时双向同步。

刷新面板只刷新视图或查询状态。超时、断网和重启后按原远端身份恢复查询，不自动创建新生成任务。恢复不了时显示「状态待确认」，禁止把重试查询当成重新提交。

## 5. 即梦接入验证清单

以下均待验证，不以本地既有 Skill 说明替代实际二进制和页面验证：

- 用户提供的安装入口及脚本内容、支持的 OS/终端、安装与升级行为。
- CLI 真实名称、版本、能力描述、结构化输出与 Skill 安装位置。
- 登录流程、授权有效状态、CLI 与内嵌页面账号是否一致。
- 能否获取指定画布的原生 URL，以及能否在 Electron 中正常加载、登录与恢复会话。
- CLI 新增或修改画布后页面是否自动更新；不支持时能否通过显式刷新定位结果。
- 提交身份、查询、取消、超时恢复及结果读取能力。
- 生成计费批准的表达方式，以及原生页面选区/修改状态的可读取范围。

验证结论决定原生视图是否启用、是否需要刷新、是否提供 CLI 面板兜底。原生页面无法嵌入不阻断 CLI 面板闭环。

## 6. 实施顺序与验收

| 阶段 | 产出 | 验收标准 |
|---|---|---|
| 1. 接入探测 | 即梦验证记录与能力清单 | 上节各项有证据、结论或明确限制，确定默认视图 |
| 2. Mock 交互 | 拓展列表、安装步骤卡、双视图容器、任务和结果卡片 | 模拟安装、登录、执行、失败、刷新、窄窗口路径可走通 |
| 3. 真实接入 | 即梦适配器和宿主任务通道 | 从环境检查到实际生成、查看和保存结果形成闭环 |
| 4. 恢复验收 | 验收记录与用户指南 | 以下用例通过；未支持能力明确降级 |

必验用例：

1. 对话提供三种系统命令，仅选择宿主适用的一条；已有兼容安装时不重复安装。
2. 安装成功但 CLI 不可发现，显示检查失败；CLI 可用但 Skill 缺失，分别显示状态。
3. 登录取消保持待登录；授权完成后通过 CLI 回查；CLI 与页面账号不一致时能提示。
4. 点击启动打开对应应用；页面失败可切换可用的 CLI 面板；刷新不提交任务。
5. AI 与面板执行产生同类任务事件和结果；原生页不具备同步能力时不显示已同步。
6. 生成后预览和保存真实产物；继续修改关联原画布和对象。
7. 提交超时、面板关闭、应用重启后查询同一任务，不重复生成或重复计费。
8. 停止能力按适配器真实能力反馈；失败和状态不确定有区别。
9. 应用/文档标签切换不丢失执行上下文；窄窗口返回对话后能继续输入。
10. 未获准应用不能通过自然语言绕过发布边界；第三方页面不能调用宿主通用执行能力。

## 7. 首期不包含

任意 CLI 自动安装、开放应用市场、多应用协作编排、通用桌面窗口嵌入，以及未获应用支持的页面选区实时双向同步。后续接入第二个应用时，再验证适配器抽象是否足够，不提前扩展框架。
