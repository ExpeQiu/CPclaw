# CPclaw 桌面交互改版

以任务为主线，采用侧栏导航、中央工作区、底部输入、右侧按需面板的布局。参考入口：https://developers.openai.com/codex/app/features 。仅借鉴信息组织，不扩展当前后端能力。

## 0.0.1 交互基线

- 左侧：新建、任务搜索、最近任务、资料与设置入口。任务标题相同时显示 ID 尾号辅助区分。
- 中央：空态引导、当前任务状态、模型调用预算、该任务的补充输入。内容来自现有工作台快照。
- 底部：多行补充输入；加入队列关联当前选中任务。Cmd/Ctrl+Enter 加入队列，Cmd/Ctrl+N 打开创建配置。
- 右侧：任务配置与诊断、材料与笔记、报告生成与变更审阅。800px 宽度采用覆盖面板，可关闭返回任务。
- 请求期间禁用重复操作，错误显示在状态栏。文件变更仍通过现有审阅接口接受或拒绝。
- 保留已有报告材料路径、取消生成和诊断导出接口。没有修改主进程、工作线程和服务协议。

## 0.0.1 能力边界（历史记录）

后端创建任务的目标仍固定为“生成带来源的报告”；底部输入是任务补充队列，不能冒充通用聊天或流式输出。材料与输出路径仍由用户填写绝对路径。审阅与个人笔记仍为工作空间级列表。
