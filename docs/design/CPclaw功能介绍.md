## 1. 定位与总体架构

CPclaw 是面向企业场景的桌面智能体工作台：员工在同一个对话入口里说明需求，由持久化的 Harness 内核会话理解意图、调用工具、交付成果；桌面外壳负责资源关联、权限确认、回执展示与资产管理。

整体分三层：

```text
┌─ CPclaw 桌面外壳（Electron，apps/desktop）──────────────────┐
│  快捷栏 / 聊天 / 文档工作区 / 技能市场 / 拓展 / 知识库 / 诊断 │
│  资源关联 · 权限确认 · 回执展示 · 版本管理                   │
└───────────────┬───────────────────────────────────────────┘
                │ cpclaw.input.v2 信息管道（x-cpclaw-pipeline: v1）
┌───────────────▼───────────────────────────────────────────┐
│  Harness 内核会话（持久、每聊天一个）                      │
│  read_resource / discover_service / call_cli /             │
│  deliver_document / submit_result / register_document      │
└───────────────┬───────────────────────────────────────────┘
                │
┌───────────────▼───────────────────────────────────────────┐
│  外部能力：TPCstore 应用 · 即梦画布 · 飞书 lark-cli ·     │
│  原生页面 Computer Use · 本机文件与终端                    │
└───────────────────────────────────────────────────────────┘
```
