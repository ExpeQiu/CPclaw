# 002 数据路径

> 状态：逻辑归属已确认；验证阶段不按数据等级限制  
> 日期：2026-10-21  
> 确认：2026-10-21，项目负责人确认数据暂时不做限制  
> 依据：技术方案第 2、5、12 节

「云端」指企业集中服务，可在内网或获准云上。部署位置仍未选定。

2026-10-21 确认：当前验证阶段，送入模型的内容不按数据等级拦截。这是暂时口径。供应商密钥仍然只放在调用端的受控配置里，不进仓库、安装包、Skill 或日志。

## 已确认

| 数据 | 权威位置 | 约束 |
|---|---|---|
| 账号、授权、资源停用 | 云端 | 本地缓存不能覆盖服务端决定 |
| 任务、运行、确认、文件操作、产物检查 | 员工 PC 宿主 | 云端只接收获准摘要，不宣布任务完成 |
| 模型上下文 | Harness 会话目录 | 宿主只保存引用，不改内核日志 |
| 供应商密钥、身份签名密钥 | 云端受控存储 | 不进安装包、Skill、日志、内核环境 |
| 员工刷新凭证 | 本机系统安全存储 | 不给界面、Harness 或脚本 |
| 企业知识原文与 Enterprise Wiki | 云端 | 索引是派生数据，不能单独授权 |
| Personal Wiki、个人/项目记忆、变更快照 | 本机，按企业/员工/安装实例隔离 | 不随普通日志上传 |
| 用户工作目录文件 | 用户磁盘 | 产物表只存引用和摘要，不默认上传副本 |
| 学习候选 | 授权后才自动提交到云端待审区 | 来源限于平台内任务、用户修正、验收和工具回执 |
| 飞书/企微应用凭证 | 云端渠道适配 | 不发到员工 PC |

模型调用链：Harness 适配 → 宿主代理 → 企业网关 → 获准模型。客户端不提交任意上游地址。

PC 不监听公网端口。办公消息由云端投递到员工主动连上的那台 PC。PC 离线则返回不可用，不排队等开机再执行。

学习默认关闭。开启后也只处理授权范围内的新信号；历史任务要单独选择才纳入。关机后停止提炼，不补跑业务任务。
