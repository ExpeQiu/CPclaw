# ADR-004：技能市场信息架构（内部 / 云端 / 本机）

日期：2026-10-29。状态：已采纳。

## 背景

早期「内置技能」Tab 实际展示云端 `source=builtin` 官方精选，「我的技能库」混入账号选用偏好与个人可用快照，与设备安装事实不一致。

## 决策

1. 技能三栏为 **内部技能 / 技能市场 / 我的技能**。
2. **内部技能**：桌面内核目录（`source=internal`），不经云端安装，不计入「我的技能」。
3. **技能市场**：组织已发布云端目录，含官方精选；不按 `excludeSource=builtin` 拆栏。
4. **我的技能**：仅当前设备 `local_skill_installs` 中的非内核技能；桌面目录请求携带 `localReleaseIds`。个人可用只在「技能创作」。
5. 平台 `market_installs` 仍表示账号选用偏好，可提示「待本机安装」，不得伪报本机已装。

## 后果

- Web 端「内部技能 / 我的技能」以空态引导至桌面。
- 场景包成员安装后进入「我的技能」并标注所属场景包标题。
- 与 [guide/技能市场.md](../../guide/技能市场.md) 对齐；旧设计文案已同步。

## 补充（连接器，2026-10-29）

- 「服务调用」投影内置即梦与飞书 CLI（`lark-cli`，可用 `CPCLAW_FEISHU_CLI`），检测走本机授权后的只读路径；飞书仅做版本 + `auth status`，不自动 Device Flow 登录。
- 「消息渠道（规划）」展示飞书机器人 / 企微占位，与服务调用分栏；正式接入仍受 Q11 约束。
- 用户 CLI/MCP 探测结果经 `connector-probe-result` / 本机 `connector_probes` 落盘；改目标后重置为未检测。
