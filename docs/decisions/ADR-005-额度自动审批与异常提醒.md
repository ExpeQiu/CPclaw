# ADR-005 额度自动审批与异常提醒

日期：2026-10-28。状态：源码实现并通过隔离测试，尚未发布到生产。

依据：用户要求余额不足时弹窗，并允许在弹窗申请新额度；当前采用自动审批模式。

1. 自动审批针对平台模型tokens额度申请，普通对话工具的权限模式仍沿用用户选择。
2. 用户主动提交申请后，服务端根据当前凭据审批并增加当前账号额度，不接受客户端指定其他员工。当前每次支持新增1至100万tokens，默认100万；不改变已用账目、并发上限或即梦积分，不执行第三方充值。
3. 申请与额度增加、审计记录在同一事务中完成。按账号和申请编号持久化幂等；前端在提交前保存待核实编号，遇响应不确定时复用，不盲目新建申请。
4. 余额校验包含下一次模型请求的最低预留。审批成功与可继续执行分别判断；仍不足时明确提示，不自动重复申请或发起模型调用。
5. 异常提示由宿主证据驱动，说明原因、影响、保留进度与下一步；原始技术错误折叠保留。额度/授权等阻塞弹窗，暂时性问题在聊天内提示，修复后更新状态。
6. 原任务无外部副作用时允许安全续接；已有生成或写入时先核实原身份和成果，不整轮重放。

平台和桌面端须配套发布。旧平台未声明申请能力时提示更新，不以客户端显示替代真实审批。
