## 目标

员工在执行模式下，依据获准材料，在单独授权的输出目录生成一份可打开的报告。报告须带可核对来源。缺章节、来源对不上、或仍有未知写入时，任务不得标为成功。

## 输入

| 输入 | P0 工程验证 | 正式业务验收 |
|---|---|---|
| 任务目标与验收条件 | 固定为「生成带来源的报告」，写入任务修订 | 由验收人确认表述，改目标必须形成新修订 |
| 本地材料 | 两份合成 Markdown：制度摘录、项目记录。只读授权到该目录 | 验收人提供的授权样本，替换合成文件 |
| 企业知识 | 不接入。不得把合成文件说成企业知识库 | P3：员工可读的固定文档版本；另设一名无权员工 |
| 输出目录 | 与输入目录分开的可写目录 | 同样分开，不能用输入目录的父目录代替 |
| 预算 | 只记录实际调用次数、时长和费用 | 上限待确认。未确认前不填写通过阈值 |

报告建议为 Markdown，便于检查标题和引用。Office/PDF 是否纳入首批产物，待样本格式确认后再加，不预先算作已支持。

## 产物

通过时必须同时具备：

- 输出目录内有一份可打开的 `report.md`
- 含四节：任务目标、材料与来源、要点、未覆盖项
- 每条依据能回到输入标识。P0 用授权目录内的文件名和段落标识；P3 改为文档版本与定位
- 宿主登记产物路径、内容摘要和检查结论
- 输入目录、输出目录之外没有本次任务写入的文件

模型回复「已完成」、内核空闲、进程退出码为 0，都不是通过条件。

## 负例

| 编号 | 条件 | 必须看到的结果 | 阶段 |
|---|---|---|---|
| N1 | 问答或规划模式要求写报告 | 拒绝写入，输出目录无新文件 | P0 |
| N2 | 目标落在授权目录外、符号链接指向外部，或兄弟目录只是同名前缀 | 拒绝，不创建文件 | P0 |
| N3 | 只授予单个输入文件 | 不能据此列出或写入父目录 | P0 |
| N4 | 章节或来源缺失 | 保留已有内容，状态为未通过，不报成功 | P0 |
| N5 | 文件已经替换、完成记录尚未写入时进程退出 | 下次启动识别已写入结果，不再次覆盖 | P0 |
| N6 | 无权员工检索或读取受限知识 | 不返回标题、片段或条数 | P3 |
| N7 | 撤权后再次引用原文 | 新请求读不到旧缓存片段 | P3 |

## 不包含

Windows、关机后续跑、多 Agent、通用网页操作、把报告自动上传为企业知识、把报告自动发到飞书或企微。上传私有副本属于后续增量，不改变本样例是否生成成功。
