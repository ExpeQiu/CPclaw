# 006 本机平台身份

> 状态：已确认，仅限本机 Mock 进程  
> 日期：2026-10-21  
> 依据：分阶段实现规划第 4 节；未决事项 Q6

外部 OIDC 产品和部署位置都还没定。P1 不接入某一个身份产品来假装已经选定。

## 决策

1. 本机平台自己签发 HS256 访问令牌。刷新令牌只存哈希。每次请求读取设备会话；过期、退出、撤销、停用都要拒绝。只校验令牌到期不算通过。
2. 空库不能无管理员启动。生产初始化用 `CPCLAW_BOOTSTRAP_FILE`。验证用 `CPCLAW_PLATFORM_SEED=fixture`，合成口令只在 `AI_MOCK_MODE=true` 时写入。
3. 桌面把刷新令牌按员工分开写成 `0600` 文件。切换当前账号只改指针，不读取上一名员工的文件。系统钥匙串等身份组件选定后再接。
4. MiniMax-M3 的额度在同一事务里预留。已知用量按返回值结算；未知用量留在未结算额，不记为零。释放并发位和结算费用是两件事。
5. 供应商密钥不出现在管理接口响应里。`start-platform.sh` 也不会把 `MINIMAX_API_KEY` 传给平台进程。

## 不采用

| 选项 | 原因 |
|---|---|
| 现在选定某个 OIDC 产品 | Q6 仍未指定产品 |
| 只校验 JWT `exp` | 撤销和停用会失效 |
| 把 fixture 口令当作正式管理员 | 口令在仓库中，只能用于 Mock |
