# 技能市场

桌面侧栏点击“技能市场”；先在设置中连接平台并登录。云端访问 `/market`，或从 `/admin` 的“技能市场与审核管理”进入。两个入口共用云端接口及页面，初始目录为空，不预置技能或专家。

## 可用功能

- 技能：内置技能、技能广场、我的技能库，搜索、详情、安装、启停、卸载。
- 场景专家：市场与已安装列表，管理员组合已发布技能，安装后可用于新聊天。组合成员不重复写入个人安装记录，卸载组合不影响单独安装。
- 连接器：本人 CLI / MCP 配置、启停和移除。桌面检测 CLI `--version` 或 MCP initialize 握手；检测结果显示在操作反馈中，不把保存配置显示成已连通。
- 技能创作：手动创建、AI 生成正文、文本文件夹与 ZIP 上传、开源来源登记、编辑草稿和另存新版本。
- 发布：草稿可设为个人使用；组织共享必须提交审核。管理员查看待审核项、填写退回意见、批准发布或撤回。已发布及待审核内容不能原地覆盖，需另存新版本。
- 用于新聊天：已安装启用的技能/专家可创建聊天，每轮请求重新检查资源是否有效，撤回、停用或卸载后阻止继续使用该技能。技能仅作为选定的方法上下文，不授予额外文件或工具权限。

## 上传与模型

上传只接收 Markdown、TXT、JSON、YAML 文本文件，目录需含 `SKILL.md`，最多 50 个文件、总正文 100KB。ZIP 仅桌面支持，压缩包最大 300KB；支持普通 stored/deflate ZIP，检查大小、CRC、路径及重复文件；不支持加密和带数据描述符的流式 ZIP，此类文件可改用文件夹上传。仅保存文本清单，不运行上传的脚本。

AI 创建复用平台聊天模型网关，Mock 环境明确提示 Mock 草稿。开源引入记录来源和必要性，由本人填写正文后送审，不自动抓取或执行外部仓库。个人知识资料可手工整理为正文；尚未提供选择知识库生成技能的接入。

技能每个版本为独立不可覆盖的发布记录；更新通过另存版本、审核发布、安装新版本和卸载旧版本完成。尚无自动版本升级。技能用于聊天的正文总长上限 6000 字，超过时提示精简，不截断执行。办公报告任务暂不绑定市场技能。

连接器本阶段提供配置和只读检测，不含第三方 OAuth/密钥存储、MCP tools 调用或 CLI 业务执行；无认证服务可直接握手，需认证的服务显示检测失败。检测结果不作为长期可用性保证。

## 数据和接口

使用现有 `platform.sqlite`，增量创建 `market_items`、`market_installs`、`market_connectors`。资源与安装以组织隔离，连接器按员工隔离；个人草稿仅本人及本组织管理员可见。现有会话撤销与权限检查适用，变更写入管理审计。市场表随现有数据库备份。

`POST /v1/market`，请求 `{ "action": "list", "input": {} }`，使用现有 Bearer 登录。操作包括 `save`、`personal`、`submit`、`review`、`withdraw`、`delete`、`install`、`toggle`、`uninstall`、`connector-save`、`connector-remove`。返回可见资源、本人安装状态、连接器及角色，服务端不信任客户端提供的角色。

## 验证

pnpm build

## 从对话提炼 Skill（0.0.20）

已完成回复下方的“提炼成Skill”会根据本轮需求、回复与实际应用执行记录生成个人草稿，随后打开技能市场编辑器。没有工具回执时，材料会明确标记为仅有对话内容，不能当作已验证的执行方法。

草稿包含用途、触发条件、输入、步骤、授权、副作用、恢复及验收说明；历史画布、节点和提交编号改为参数，凭据不作为材料传入。草稿默认版本为 1.0.0，不自动启用、安装或发布，审阅后沿用“个人使用”或“提交审核”流程。

同一轮重复点击会打开已有草稿；不同轮次产生同名技能时会另用名称保存，避免覆盖。草稿可在技能市场中继续编辑。
