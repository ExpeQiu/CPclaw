# 企业技能市场

更新日期：2026-10-29。本文说明模块职责与使用流程；文末「规划与当前版本的差异」记录仍未完成的能力边界。

技能市场包含技能、场景专家、连接器、技能创作四个入口；管理员另有审核管理。桌面侧栏点击“技能市场”打开；先在设置中连接平台并登录。Web 端可访问平台 `/market`，用于浏览、创作与审核，本机安装和执行在桌面完成。

## 页面导航总览

| 模块 | 管理内容 | 主要操作 |
|---|---|---|
| 技能 | 内部技能、云端技能市场、本地已安装的我的技能 | 查看、安装、使用、更新和卸载；内部技能随内核维护 |
| 场景专家 | 云端按场景组织的技能组合安装包 | 查看成员、一键安装、一键更新和使用 |
| 连接器 | 外部服务连接；后续扩展消息渠道 | 配置、登录、检查和管理连接 |
| 技能创作 | 新技能、已有技能的新版本或副本、导入的技能包 | 对话创作、历史提炼、编辑、试用和提交审核 |
| 审核管理（管理员） | 云端收到的技能提交与已发布内容 | 审核、退回、发布给全员和维护版本 |

## 找到并使用技能

“技能”统一管理所有技能，分为三个分类：

| 分类 | 内容范围 | 使用方式 |
|---|---|---|
| 内部技能 | 内核自带的内置技能 | 查看用途并使用，随内核维护；不计入“我的技能” |
| 技能市场 | 云端服务器提供的技能；面向全员的目录只展示已审核发布的内容 | 查看详情，安装到本地；有新版时更新 |
| 我的技能 | 当前设备已经安装的技能，不包含内核技能 | 使用、查看依赖、更新和卸载 |

官方精选属于云端技能市场的内容来源，不等同于内核的内部技能。个人创作或导入的技能只有完成本地安装后才进入“我的技能”；保存草稿、提交审核或云端发布都不等于本地安装。通过场景专家安装的非内核成员技能也归入“我的技能”，标注所属场景包。

默认云端目录不自动写入演示数据，管理员发布正式内容后才会出现。云端草稿、待审核和被退回的内容不出现在面向全员的技能目录中。

可搜索名称、用途、标签和别名，按工作分类、账号安装偏好筛选，并按推荐、更新时间或名称排序。页签分别保留搜索条件。目录按稳定技能身份展示版本；详情可查看其他版本。

详情说明适用范围、输入要求、效果示例、结构检查、依赖、方法正文、文件清单、版本与更新说明。合成示例、结构检查和真实试用是不同证据，不因“官方”或“审核通过”就表示业务效果已经验证。

从云端技能市场选择技能，查看详情后安装到桌面。安装会下载并校验固定版本，完成后显示在“我的技能”。安装状态与账号偏好分开：另一台电脑不会因账号已经选用就显示安装成功。安装失败保留已有版本；下载中可取消。

安装启用后可“用于新聊天”或“用于当前对话”。有必填输入时先准备材料；当前项目支持从文件选择器明确选取文本材料，发送时再读取真实内容。选用不会自动发送任务或产生生成费用。

输入框上方显示技能及固定版本；“解除技能”保留原聊天、产物和项目材料，后续不再注入该方法。运行中不可替换或解除；完成或停止后再操作。选用技能不会修改当前对话权限模式，也不会重复索取仍有效的授权。

输出检查结果与回复完成状态分别展示：结构通过、检查未通过、未配置检查规则；Mock 明确标记。文件或应用结果仍以实际产物和服务终态为准。

## 安装、依赖和版本维护

“已安装”只表示本机存在经过校验的制品。依赖页面可以查看缺失程序、未配置的服务或不兼容环境。已配置但尚未实测的连接明确显示仍待发现；执行前通过现有宿主通道实际发现工具，继续遵循账号与对话权限。

新版本出现后，已装旧版本提供更新入口。详情可比较正文和依赖变化，选择安装新版或切回仍获准的旧版。更新只影响后续选用，已有聊天继续使用绑定的版本，不静默替换。

卸载移除安装引用，保留历史任务与成果；仍被运行或组合引用的制品不直接清除。专家卸载保留用户独立安装或其他组合需要的成员。

管理员常规下架会阻止新安装，但已有安装可按固定版本继续使用。紧急停用会阻止新运行和后续受控工具调用；已经发出的外部请求须按服务实际能力查询或取消，不能承诺立即收回。

## 创作和试用

技能创作支持以下五种主要方式，统一进入草稿编辑、检查与试用流程：

| 创作方式 | 操作与预期结果 |
|---|---|
| 对话创作 | 描述希望完成的任务，通过对话补充要求并生成新技能草稿 |
| 从历史对话提炼 | 选取已有对话中的方法、修正和结果，提炼为可重复使用的技能草稿 |
| 更新已有技能 | 对自己维护的技能创建下一版本；改编其他技能时复制为个人草稿，保留来源与原版本 |
| 从零新建 | 手动填写用途、输入、执行步骤、依赖与输出，创建全新技能 |
| 导入技能 ZIP 包 | 选择技能包，预览内容并检查后导入草稿，再编辑或试用 |

现有文件夹导入和开源来源登记继续保留。导入内容与自行创作内容使用相同的检查、试用和审核流程，不因来自 ZIP 包而直接发布。

编辑器分区填写用途、适用边界、输入参数、依赖、方法、输出章节、样例和更新说明。显式保存草稿，离开未保存内容时提示；并发修改会要求刷新比较，避免覆盖。

保存后查看结构检查并试用。试用使用固定草稿修订，仍走正常任务和权限通道；修改正文或依赖后，旧试用不能用于证明新修订有效。试用详细结果保存在本机，并区分 Mock 与真实执行；提交共享时可附带当前修订的最小试用摘要，管理员查看时会标明作者宿主报告及 Mock 状态。旧修订报告不能用于新修订。

个人使用会生成冻结的个人快照；提交审核不打断既有个人使用。已冻结内容需另存新版本修改；提交、退回或修改下一版本不改变原发布版本。个人内容目前保存于平台，本组织管理员可见，不表示只保存在本机。

从对话提炼沿用回复底部图标入口，不在每次短回复都出现：至少两轮用户发言，且该轮有较充实结果（应用回执或足够长的正文）才提供。材料来自本轮需求、总结和实际工具回执；没有回执时明确为仅对话内容，不冒充执行验证。历史实例编号、路径与凭据不能固化到方法中。同一轮重复提炼复用已有草稿。回复底部另有点赞评价，记录在本机会话中。

## 提交云端、审核与全员发布

创作完成后可以先个人使用，也可以提交到云端技能市场。个人快照完成本地安装后进入“我的技能”；是否提交共享由作者选择。

组织共享的完整流程为：

1. 作者完成编辑、检查和试用，保存本次准备提交的固定版本。
2. 从创作列表提交到云端技能市场，补齐用途、版本说明、示例、试用摘要及适用的来源和许可资料。
3. 提交后进入“待审核”，由云端管理员查看固定修订、检查结果、试用证据和变更内容；此时其他员工不能从市场安装该提交。
4. 管理员审核后发布，技能进入云端市场，对当前企业组织全员可见、可安装和使用。发布不会自动安装到每位员工的电脑，也不会自动启用。
5. 如被退回，作者查看意见、修改并重新检查和试用，再提交审核；待审时也可主动撤销提交。

首次发布和后续版本更新都需要管理员审核。已发布版本不能直接覆盖；新版本审核发布后，已安装用户可查看更新说明并选择更新。待审核、退回或修改下一版本不影响仍获准使用的旧版本。

作者可在“我的创作”查看草稿、个人可用、待审核、需修订和已发布状态。审核结果通过应用内通知反馈。管理员可在详情处理反馈、设置精选排序、常规下架或紧急停用。

## 场景专家

场景专家来自云端服务器，主要按工作场景组织技能。同一场景所需的多个技能可以组合成一个安装包，用户无需逐个查找和安装。

1. 在“场景专家”浏览场景，查看适用任务、包含的技能、版本及所需连接器。
2. 一键安装场景包，统一展示已有成员、待安装成员和失败原因。全部必需成员安装完成后，继续检查连接器和账号是否就绪。
3. 安装后的场景包可直接选择任务使用；非内核成员技能同时归入“我的技能”，便于单独查看与使用。
4. 云端发布场景包新版本后，可一键更新该场景包及需要更新的成员。场景包锁定成员版本，单个技能有新版时不会自动改变整个组合；更新失败保留原可用版本。

卸载场景包时，保留用户独立安装或仍被其他场景包使用的成员。场景包安装完成、连接器已就绪和实际任务完成分别展示，部分成员成功不能显示为整个场景已经可用。

## 连接器

连接器用于连接其他应用或服务，当前重点是通过 CLI 方式连接即梦、飞书等服务。技能说明如何完成工作，连接器提供实际访问服务的能力；安装技能或场景包后，仍需完成相应连接配置与登录。

1. 打开“连接器”，选择所需服务，按页面说明添加连接。
2. 完成必要配置与账号登录，检查服务是否可用，以及当前账号具备哪些操作权限。
3. 返回依赖该服务的技能或场景专家，重新检查并继续任务；日常可在“我的连接”管理账号、查看状态和处理失效连接。

连接器规划包含两类用途：

| 用途 | 示例 | 用户获得的能力 |
|---|---|---|
| 服务调用 | 即梦 CLI、飞书 CLI | 让助手使用已连接服务完成生成、文档处理等任务；各服务按实际支持范围接入 |
| 消息渠道（后续规划） | 飞书机器人、企业微信 | 从对应消息渠道与助手交互；具体能力随渠道接入提供 |

服务调用与消息渠道的状态分别检查。连接飞书 CLI 不代表已经接入飞书机器人；消息渠道接入也不代表自动取得该平台全部业务权限。服务配置与任务中的应用操作共用已有连接，操作说明见 [拓展应用](拓展应用.md)。

## 官方内容维护

管理员点击“导入官方精选”，幂等导入六个完整方法草稿：材料报告、会议纪要与行动项、文档摘要与证据提取、产品需求梳理、方案比较、工作周报整理。包含输入、方法、章节要求和合成样例；需在目标环境试用、审阅后发布，不自动安装或向全员启用。

六个成员发布后，可在技能创作点击“创建场景专家草稿”，生成“办公材料助手”和“产品工作助手”。组合锁定成员版本，使用时选择具体任务，只加载对应成员方法。组合需单独检查、试用与发布，不引入新 Agent 运行时。

通知提供审核结果、更新、下架与停用提示。问题反馈默认只记录用户主动填写的说明，不自动上传聊天或文件正文。

## 规划与当前版本的差异

- 技能三栏已调整为“内部技能 / 技能市场 / 我的技能”：内部技能由桌面内核提供；官方精选归入云端技能市场；我的技能仅本机已装的非内核技能（个人可用只在「技能创作」）。
- 场景包支持一键安装与一键更新（按锁定成员版本同步）；成员进入「我的技能」时标注所属场景包。部分成员成功不会显示为整个场景可用。
- 连接器页已投影内置即梦，并支持分层检测落盘（程序 / 握手 / 登录 / 可调用）；任务开始时仍会重新发现。通用 CLI/MCP 探测结果写入连接配置；场景包提供安装与连接分态就绪检查。
- 飞书 CLI（官方 `lark-cli` / `@larksuite/cli`）已作为内置服务调用连接投影：可检测版本与 `auth status`；可用 `CPCLAW_FEISHU_CLI` 覆盖路径。连接 CLI ≠ 接入飞书机器人。
- 连接器页已分「服务调用 / 消息渠道（规划）」；飞书机器人与企业微信仍仅占位，正式接入依赖 Q11（测试应用与回调网络）。
- 保存草稿、提交审核、云端发布与本地安装是不同操作。个人内容的现有保存位置及管理员可见性仍以“创作和试用”一节说明为准，本次规划未将草稿改为仅保存在本机。

## 导入和当前限制

- 文件夹仅支持 Markdown、TXT、JSON、YAML；最多 50 个文件，正文 UTF-8 合计 100KB，需唯一非空 SKILL.md。目录、隐藏文件、重复路径和非文本内容会检查。
- ZIP 仅桌面支持，压缩包最多 300KB；不支持加密和数据描述符流式 ZIP，可改用文件夹导入。压缩校验、CRC、路径和大小限制仍有效。
- 实际运行读取 SKILL.md 入口，不把上传 JSON 清单直接当作方法。附属文本随版本落盘；入口或组合正文合计上限 6000 字，暂不承诺自动加载所有 references。
- 发布包包含文件、样例和元数据，总大小上限 250KB；过大的草稿会在个人使用或提交前提示精简。
- 技能任务输入合计上限 6000 字，单条聊天仍有原长度限制；过长时精简或通过项目材料入口选择资料。
- 开源引入首期登记固定来源与许可，并导入选定文本，不自动抓取或执行任意仓库。
- CLI/MCP 复用已有应用服务。保存配置、版本检测、握手、工具发现与业务授权分别判断；不增加通用 OAuth 或假定任意应用已接通。
- 目前共享范围为组织；部门/项目定向分发、本地未上传草稿、基于所选知识资料生成技能和更多文件格式继续按独立需求实施。
- 没有执行真实模型/第三方任务的测试不能计为正式业务验收。历史 0.0.21 发布已按用户授权同步更新本机与云端，正式技能内容仍由管理员明确导入、审核和发布；该历史记录不代表本轮规划已上线。

## 开发验证与迁移

市场与旧企业 Skill API 共用同一领域服务，发布使用 skills / skill_releases / skill_submissions，market_items 保留作者工作副本和兼容 ID。旧记录增量迁移，不按标题合并，旧撤回保守迁移为停用。原账号安装偏好需在具体设备补做实际制品安装。

```sh
pnpm build
pnpm test
node --test apps/desktop/test/*.test.mjs
pnpm test:desktop:market
```

验证使用隔离临时数据；新版截图位于 docs/verification/market-v2/。实现范围和证据见 [本轮验收记录](../docs/verification/技能市场功能实现20261026.md)。

### 登录会话与市场首屏

市场首屏会并发触发列表与目录请求，每个请求都先换取访问令牌。刷新令牌是单次使用语义，桌面端已对续期做单飞收敛（同一时刻只发一次续期请求，其余调用方复用同一结果），并用文件锁覆盖多个桌面实例的跨进程竞争，避免并发续期互相作废令牌。

若市场报「登录凭证无效」，按 [故障恢复](故障恢复.md#技能市场报登录凭证无效) 重建会话。回归与线上核验：

```sh
node --test apps/desktop/test/session-refresh-race.test.mjs
node scripts/verify-market-session.mjs
```
