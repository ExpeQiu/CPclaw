# macOS 桌面应用打包

当前交付：CPclaw 0.0.25（本机拓展、服务分类、Computer Use WEB/APP 目录校验），macOS Apple Silicon（arm64）。Electron 33.4.11，内置官方 Node 22.23.3，无需安装 Homebrew、Node 或 pnpm 即可启动应用。

## 使用

交付目录：`/Users/expeqiu/Documents/产品设计/CPclaw桌面APP`。

- `/Applications/CPclaw.app`：当前已安装的 0.0.25，双击运行。
- `0.0.25/CPclaw-0.0.25-mac-arm64.dmg`：拖拽安装介质。
- `0.0.25/CPclaw-0.0.25-mac-arm64.zip`：分发压缩包，解压得到 CPclaw.app。建议将应用放在本机 Applications 目录运行，避免文件同步服务给 bundle 添加 FinderInfo 属性，干扰签名验证。
- 同名 JSON：版本、架构、本地签名类型与压缩包 SHA-256。

默认数据目录为 `~/Library/Application Support/CPclaw`，沿用已有登录数据。包内不包含账号令牌、`.env` 或用户材料。新机器可在桌面「设置与诊断」中连接平台并登录，见 [桌面聊天](桌面聊天.md)。

此版本使用 ad-hoc 本地签名，没有 Developer ID 签名和 Apple 公证。跨机器下载后可能需要在系统“隐私与安全性”中允许打开，不作为正式签名发行版。

聊天需要包含 `/v1/chat/stream` 的新版平台；真实模式与 Mock 模式由平台决定，Mock 回复明确标注。默认报告链路为 Mock；真实模型仍需原有远程平台与会话配置。0.0.7 起，独立包内置已编译的 Harness SDK、CLI、配置、插件和运行依赖，无需外部 Harness 源码或 tsx。普通聊天仍沿用云端流式接口；内置 Harness 用于已有的报告执行分支。

## 重建

1. 从 Node 官方下载 `node-v22.23.3-darwin-arm64.tar.gz`，按该版本 `SHASUMS256.txt` 校验后解压。
2. 在仓库安装锁定依赖，然后运行：

```bash
CPCLAW_PACKAGE_NODE_DIR=/path/to/node-v22.23.3-darwin-arm64 pnpm package:desktop
```

默认生成到仓库 `dist/`。可用 `CPCLAW_PACKAGE_OUTPUT_DIR` 指定本地构建目录，避免外置文件系统的 AppleDouble 文件影响构建。脚本拒绝覆盖已存在的产物目录。采用 Electron 官方支持的手工打包布局，无需增加打包工具依赖。

## 0.0.7：随 DMG 内置 Harness

安装介质为 `CPclaw-0.0.7-mac-arm64.dmg`，拖拽 CPclaw.app 到 Applications 即可安装。另保留 ZIP 和包含 DMG/ZIP SHA-256 的 JSON 清单。此版本仍为 macOS arm64、本地 ad-hoc 签名。

- 包内 `Contents/Resources/harness` 包含 Harness 0.1.6-alpha.2 的编译产物、SDK、CLI、配置、插件、运行依赖及许可证；`manifest.json` 记录来源提交和依赖包数量。构建源是本机已编译检出，来源提交并不表示工作区没有本地变动，分发完整性以安装包 SHA-256 为准。
- 安装模式由 `workspace-client.mjs` 自动选择包内 Harness，忽略外部 `CPCLAW_HARNESS_ROOT`；不加载开发用 tsx 或源码映射钩子。Harness 子进程使用同一个内置 Node 22.23.3。
- 本次完成的是内核打包。普通聊天不自动切换为 Agent 循环。已有报告分支仍按 `CPCLAW_REPORT_MODEL_MODE=real`、`CPCLAW_REPORT_ENGINE=harness` 启用，并需要有效的平台连接与会话。
- 构建时可用 `CPCLAW_HARNESS_ROOT` 指定已编译的 Harness 检出目录；缺少 SDK/CLI 或必要依赖会失败。安装用户无需设置该路径。
- 打包自动运行 `scripts/verify-bundled-harness.mjs`：清空开发环境、使用包内 Node，检查依赖链接不越出应用，启动真实工作进程，并以本地模型夹具执行材料工具、模型续答、子进程回收。验证失败不生成分发介质。

手工复验：

```bash

```

验收使用本地模型夹具，不调用真实 MiniMax；这不等于完成真实云端报告验收。未自动替换本机已有安装和用户数据。
