# 对话文档与智能交付

当前版本：CPclaw 0.0.6。

## 自然描述工作

直接描述你要完成的工作，例如“明天要开项目会，帮我准备一份同事拿到就能执行的资料整理提纲”。不需要勾选生成选项，也不需要补上“文件”“Markdown”或指定扩展名。

模型结合对话和当前文档判断交付方式：普通问答直接回答；需要可复用成果时，调用文档交付工具。应用校验文件名、正文与修改目标，在回复完整结束后保存实际 `.md` 文件，消息中显示文件卡片并打开右侧文档工作区。如果目标不明确，仍可能先询问必要的内容信息。

当前每轮支持交付一个 Markdown 文档。失败或取消的工具调用不会创建完整文档；保存失败会显示原因，回复正文保留。已完成的普通文字回复仍可点击“保存为 .md”手动留存，这不是开始任务的必要步骤。

## 查看与修改

右侧工作区左边是文档，右边是文件与结构：

- 顶部标签切换文档，路径栏显示当前文件与版本。
- 文档区支持阅读、源文、打开、另存为、定位和刷新；“保存位置”展开显示完整本地路径。
- 右边“文件”以文档和版本分层展示实际产物，可展开收起、筛选及切换历史版本。
- “大纲”按标题层级展示结构，点击可跳到正文对应位置。
- 正文与结构树独立滚动；“展开”提供更大的阅读区，“收回”或关闭后返回聊天。

可以直接追问“最后补上验收标准，其他内容保持不变”，模型会结合当前文档生成新版本。也可以点“继续修改”明确选定某份历史版本。新文件不覆盖旧版。文档数量较多或所指不明确时，应明确对象，模型也可以询问。

## 本地保存与另存为

默认目录：`~/Library/Application Support/CPclaw/documents/<员工编号>/<文档ID>/r<版本>/`。文件与聊天关联，重启后保留；文件名由模型选择或遵循用户的明确命名要求。

“打开”使用系统默认应用，“定位”在 Finder 中显示实际文件。“另存为”通过系统对话框选择 `.md` 位置，取消不会写出，已有目标由系统提示覆盖。另存为是导出副本，之后修改维护 APP 内版本，不自动同步到已导出的副本。

如果在外部编辑了 APP 内文档，可刷新预览查看当前内容。应用会检查生成期间的内容变化，发生冲突时不会覆盖原文，聊天回复仍保留。当前自动编辑上下文最多提供12份文档的标识与名称，以及当前文档不超过10000字的正文。

## 权限与展示

文件只按当前账号和聊天访问。模型不能指定任意磁盘目录，APP 仅在文档目录中落盘；另存为由用户选位置。模型不会因为生成正文就被授予额外文件或应用权限。

预览支持标题、列表、代码块、段落、加粗及行内代码，HTML和脚本不执行；其他标记可通过源文查看。文件不会自动上传云盘，修改时所选文档正文随模型请求使用。

### 项目文件夹

在“结构与层级”中选择“文件夹”，可查看当前项目文件夹中的文件，展开子目录后查看其内容。文件包含隐藏文件与各种文件类型；点击文件可在系统文件夹中定位，点击“刷新”可更新目录。符号链接显示为链接，不继续展开。未关联项目时会提示先选择项目。“文件”仍展示聊天成果及版本，“大纲”展示当前文档标题。
