# 云端管理台

当前入口：<http://47.113.225.93:3928/admin>。

浏览器访问平台地址的 `/admin`；访问根地址会自动转到管理台。使用本组织管理员账号登录，普通员工无法读取或执行管理接口。凭证仅保存在当前页面内存，刷新或关闭页面后重新登录；登录期间访问凭证到期会自动续期，退出登录会撤销当前会话。

## 功能与操作

| 页面 | 可执行操作 |
| --- | --- |
| 服务概览 | 查看本组织员工数、正常账号数、活动会话、已结算用量和服务状态 |
| 员工与权限 | 搜索员工、新增账号、修改姓名、调整管理员/员工角色、重置口令、停用 |
| 设备会话 | 查看员工设备与会话状态、撤销会话，包含当前会话 |
| 配额与用量 | 查看总额度、已结算、未知用量预留、进行中预留和并发；调整总额度及并发 |
| 企业知识库 | 新增企业库、设置访问成员、维护文档；复用桌面文档修订校验 |
| 应用连接器 | 查看云端登记 CLI/MCP 的归属和检测层级；组织禁用或解除禁用 |
| 模型用量台账 | 按员工分页查看请求、预留与实际用量、增额申请记录 |
| 企业学习与发布 | 学习提交开关、候选审核、资源下架、发布 Wiki 修订审核及来源撤权 |
| 上传与同步 | 上传状态、字节数、用途、日志同步回执；不开放私人正文 |
| 渠道与设备 | 查看预留 IM/设备的已有登记与投递状态；不表示真实渠道接入 |
| 桌面管理对照 | 显示每个桌面模块的管理归属、云端接口、入口与接入状态 |
| 模型状态 | 查看模型、密钥配置状态和 Mock/真实模式；不显示密钥 |
| 技能审核 | 查看完整内容、检查结果、提交证据和反馈；通过并发布、驳回修订、下架、紧急停用 |
| 操作审计 | 按操作者、操作、时间、对象筛选，分页查询并导出当前页 CSV |
| 数据备份 | 创建数据库备份，查看本组织最近 50 次回执与文件是否存在 |
| 诊断包 | 查看本组织成员主动上传的最近 100 个诊断包及内容，查看动作进入审计 |

新增员工编号以小写字母开头，允许小写字母、数字、短横线，最多 32 字符。姓名最多 40 字，口令 8–128 字符。默认配额为 1,000 Tokens、并发 1，创建后可调整。总额度范围 1–1,000,000，并发范围 1–8；调整不清零历史消耗。

修改角色或重置口令会撤销该员工全部活动会话。当前管理员不能降低自己的角色或重置自己的口令，应由另一管理员操作。停用账号会写入权威撤权台账，恢复旧库也保持停用；重新入职使用新编号。页面不提供账号重新启用或删除。

## 边界

- 所有员工、配额、审计、技能和诊断数据受服务端组织及角色校验保护。
- 诊断页读取显式上传、标记为 `diagnostic-pack` 的制品，不开放其他私人文件。组织管理员可以查看组织成员上传的诊断包。
- 模型密钥和连接通过服务器环境配置维护，本页只显示状态；密钥存在不等于供应商调用成功。
- SQLite 备份包含多个组织数据，页面不提供整库下载；备份回执只显示本组织创建的备份。文件上传数据与权威撤权台账需另行保全。
- 恢复需停服并由运维执行；恢复模块和桌面宿主源码兼容上限已对齐 schema 4。已验证来源撤权与组织连接器策略在恢复旧库后仍回放；完整灾备还需保全台账、文件与运行配置。
- 部署升级、服务重启、网络配置和服务器日志不属于此次业务管理台范围。

## 企业治理与桌面生效边界

- 企业库管理复用 `/v1/knowledge`，不另建一份副本。成员权限变更在桌面下次读取时检查；旧文档修订提交会被拒绝。管理台编辑名称和权限时也使用 `baseUpdated` 检查并发改动。
- 连接器组织策略保存于 `org_connector_controls`，用户修改连接器不会覆盖组织禁用。平台返回 `ownerEnabled`、`adminBlocked` 和生效后的 `enabled`；桌面原有服务目录过滤即遵循该结果。
- 组织禁用在桌面下一次获取服务目录时生效，不终止正在本机执行的进程。内置即梦、飞书 CLI、Computer Use、本机文件与目录驱动不是云端登记连接器，继续使用本机授权流程。
- 组织禁用/解除禁用同时进入权威台账。恢复旧库时回放最后的明确策略，保持最新政策修订，不重新开启已禁用服务。
- 企业学习与发布 Wiki 是已有领域服务的管理入口；当前桌面没有自动上传学习候选或发布 Wiki 的流程。IM 消息渠道仍属预留能力。
- 审计及新增台账每页 25 / 50 / 100 条；审计可筛选操作者、操作、起止时间、对象。CSV 只导出当前页，导出值做公式前缀转义。
- 连续登录失败按来源地址与账号限流：单账号/地址 15 分钟最多 10 次失败，单来源地址 15 分钟最多 100 次失败。超过限制返回 429 和 Retry-After；此为进程内限流，多副本部署需共享入口限流。
- 本次沿用现有账号登录和 HTTP 地址，不引入 SSO、域名、HTTPS 或新的服务器运维页面。
- 安装于 `/Applications/CPclaw.app` 的 0.0.35 已核对接口路径与连接器有效开关逻辑；未修改或重装已安装桌面 APP。桌面宿主兼容常量修复属于源码状态。

## 接口

管理操作继续使用 `POST /v1/admin/manage`，请求 `{ action, input }`。服务端首先校验管理员身份，再按当前账号的组织查询；不接受客户端提供组织切换。新增操作：

| action | 用途 |
| --- | --- |
| catalog | 桌面/云端模块对照与服务兼容信息 |
| audit-query | 审计筛选与分页（actor/action/from/to/q） |
| usage / quota-requests | 模型请求和增额申请台账 |
| connectors / connector-control | 连接器元数据、组织禁用策略（id/blocked/revision） |
| uploads / log-receipts | 上传元数据与日志同步回执 |
| learning-policy / learning-set | 企业学习开关 |
| learning-candidates / candidate-read / learning-review | 候选查询、正文审阅、按 version 审核 |
| resources / resource-read / resource-retire | 共享资源查询、审阅与下架 |
| wiki-revisions / wiki-read / wiki-review | Wiki 历史修订、正文、按 revision 审核 |
| originals / original-read / original-revoke | 发布 Wiki 的来源原文查询、阅读与撤权 |
| integrations | 预留 IM 和设备登记元数据 |

分页 action 接受 `page`（从 1 开始）、`pageSize`（1–100）、`q`（最多 100 字）。响应包含 `rows/page/pageSize/total`。候选、资源、Wiki、原文按标题检索；其他台账按员工编号检索。内容审阅、写操作与策略变更进入审计。
