# 应用服务与自然对话

CPclaw 使用一个对话入口，不要求选择“对话模式”或“CLI 模式”。直接说“调用即梦生成一辆跑车图片”“去某个 SaaS 查询待办”，AI 会请求对应服务。普通问答直接回复，明确要求报告或文档时交付文档；执行任务不能用 Markdown 执行单代替。

## 选择与配置

输入框工具栏的“应用服务”和左侧“拓展”均打开服务选择弹窗。左侧列出服务，右侧显示配置与检查说明；点击列表只查看详情，不执行命令。“选择并打开”绑定当前对话并展开右侧操作面板。已绑定服务用于理解后续操作，不会让普通聊天强制执行。

内置即梦画布支持图片、视频、音频及对应画布操作；具体命令、参数和模型从本机已安装 CLI 实时获取。其他本机 CLI 可通过技能市场中的连接器配置，必须填写程序的绝对路径。网页和 SaaS 可配置 MCP HTTP 服务地址，通过实际 tools/list、tools/call 接入。纯网页地址或没有 CLI/MCP 接口的应用不会因此自动获得浏览器操作能力。

明确点名可用服务时，无需先打开服务弹窗；服务存在歧义时才弹窗选择。未安装、未登录、服务停用或缺少执行接口时显示具体原因，不伪造成功。

## 执行与结果

AI 的应用操作由 Harness 的 service_action 工具执行。宿主先发现 CLI help/schema 或 MCP 工具目录，随后逐步执行，每步的实际回执会返回 AI，右侧显示进度与结果。执行中可以停止；更换服务须先停止当前任务。切换账号或会话会中止本机未完成的授权及后续操作。

即梦生成先保存节点，再取得实际报价；积分批准由本机弹窗处理，AI 不能填写或接收批准凭据。运行提交号在调用前保存；超时后查询原提交，不自动重复生成。图片下载后检查实际文件类型、字节数和校验值，并在右侧预览。画布使用 CLI 返回的官方 webUrl 打开原生页面；网页登录与 CLI 认证分别处理。

MCP 服务提供其实际工具及参数，用户确认服务地址与调用内容后执行。服务若需要独立账号授权，须先完成该服务支持的登录；本版本不提供通用 MCP OAuth 客户端，也不代替 SaaS 自身的业务权限。

## 授权

本机命令和服务调用均需宿主确认，选择服务本身不授予执行权限。详情见 [本机命令执行授权](本机命令授权.md)。服务配置、聊天、执行回执保存在相应账号和对话下；凭据、积分 token 与临时签名地址不作为回执发送给模型或写入任务记录。

测试中的“工单系统”“包内 CLI 验证夹具”等仅存在于隔离测试数据中，不是默认服务或真实业务接入。
