# 应用服务与自然对话

CPclaw 使用一个对话入口，不要求选择“对话模式”或“CLI 模式”。直接说“调用即梦生成一辆跑车图片”“去某个 SaaS 查询待办”，AI 会请求对应服务。普通问答直接回复，明确要求报告或文档时交付文档；执行任务不能用 Markdown 执行单代替。

## 选择与配置

输入框工具栏的“应用服务”和左侧“拓展”均打开服务选择弹窗。服务按三类组织：

| 类型 | 用途 | 如何添加 |
|---|---|---|
| Computer Use | 直接控制网页；点击/输入走可访问树，登录与支付需请示 | 内置原生页、添加网页地址，或 MCP 网页/SaaS |
| 驱动应用 | 选定本地应用/项目文件夹，代码层读写与终端驱动，右侧可见交互 | 加载应用文件夹；自动识别应用目录或普通项目 |
| CLI 三方应用 | 绑定本机 CLI 后按自动化流程驱动 | 内置即梦、飞书 CLI（`lark-cli`）；其他 CLI 在技能市场配置连接器 |

左侧按类型切换列表，右侧显示配置与检查说明；点击列表只查看详情，不执行命令。“选择并打开”绑定当前对话并展开右侧面板。已绑定服务用于理解后续操作，不会让普通聊天强制执行。

内置即梦画布支持图片、视频、音频及对应画布操作；具体命令、参数和模型从本机已安装 CLI 实时获取。飞书服务调用复用本机官方 `lark-cli`（可用环境变量 `CPCLAW_FEISHU_CLI` 指定路径）；技能市场「连接器 → 服务调用」可检测版本与登录态，**不**等同于飞书机器人消息渠道。其他本机 CLI 须填写程序绝对路径。网页和 SaaS 可配置 MCP HTTP 服务地址，通过 tools/list、tools/call 接入。

具备页面入口的服务可在右侧打开「原生页面」。Computer Use（`browser-page` / 本机网页）先发现能力，再打开允许源内页面、读取可访问树，并按 `ref` 操作。未绑定允许源不能任意打开网页。登录、支付或密码输入由宿主强制确认，不会代填凭据；即梦生成与积分仍优先走 CLI。驱动应用以所选文件夹为工作目录执行本机文件与终端工具。

明确点名可用服务时，无需先打开服务弹窗；服务存在歧义时才弹窗选择。未安装、未登录、服务停用或缺少执行接口时显示具体原因，不伪造成功。

## 执行与结果

AI 的应用操作由 Harness 的 service_action 工具执行。宿主先发现 CLI help/schema 或 MCP 工具目录，随后逐步执行，每步的实际回执会返回 AI，并只在右侧「自动工作流」显示进度与结果；左侧对话不重复列出过程步骤。执行中可以停止；更换服务须先停止当前任务。切换账号或会话会中止本机未完成的授权及后续操作。

即梦生成先保存节点，再取得实际报价；积分批准由本机弹窗告知报价与预留额度（无可编辑上限），AI 不能填写或接收批准凭据。运行提交号在调用前保存；超时后查询原提交，不自动重复生成。图片下载后检查实际文件类型、字节数和校验值，并在右侧预览。画布使用 CLI 返回的官方 webUrl 打开原生页面；网页登录与 CLI 认证分别处理。

MCP 服务提供其实际工具及参数，用户确认服务地址与调用内容后执行。服务若需要独立账号授权，须先完成该服务支持的登录；本版本不提供通用 MCP OAuth 客户端，也不代替 SaaS 自身的业务权限。

## 授权

本机命令和服务调用均需宿主确认，选择服务本身不授予执行权限。详情见 [本机命令执行授权](本机命令授权.md)。服务配置、聊天、执行回执保存在相应账号和对话下；凭据、积分 token 与临时签名地址不作为回执发送给模型或写入任务记录。

测试中的“工单系统”“包内 CLI 验证夹具”等仅存在于隔离测试数据中，不是默认服务或真实业务接入。


## 保存创作过程（0.0.20）

已完成回复下方显示“保存文档”。点击后把到本轮为止的对话整理成 Markdown，写入项目的 `CPclaw成果` 文件夹（未归入项目时写入本机账号目录），并在右侧文档与预览中打开。原回复保留，也可通过文档卡片另存为或打开。

同一行提供点赞评价；“提炼成 Skill”弱化为图标，仅在多轮对话且结果较充实（含应用回执或较长正文）时出现，详见 [技能市场](技能市场.md)。

## 加载应用文件夹

打开“拓展 → 驱动应用”，点击“加载应用文件夹”。可选择 TPCstore 根目录、其中的 CutPot 应用文件夹，或普通项目。选择后先显示识别结果，不会立即执行应用程序。

- TPCstore 目录：点击“检查并查看应用”，再选择应用卡片的“连接并打开”。
- CutPot 文件夹：自动找到所属清单，直接“连接并打开”；不必填写应用目录、端口或页面地址。
- 普通项目：显示“作为项目添加并打开”，通过文件与终端驱动，不假装已启动应用服务。

“最近的 TPCstore”复用上次来源。已有工作台地址可在“手动配置工作台”中填写。独立应用清单尚无受支持的来源/适配时会说明原因；损坏清单不会自动当作普通项目添加。

连接期间显示检查与连接状态，避免重复提交。取消授权保留选择，可继续加载；失败显示原因并支持原地重试。重复添加复用已有服务。成功后绑定当前对话并打开工作区；当前任务未结束时先保留已添加应用，任务结束后再打开。

CLI 修改后仍需刷新工作台。关闭面板或移出列表不会删除工程，也不等同于停服务。CutPot 使用宿主独立数据目录；原生 CLI 自动绑定对应地址和目录。源码验证与剩余边界见[文件夹加载验收](../docs/verification/app-folder/README.md)。
