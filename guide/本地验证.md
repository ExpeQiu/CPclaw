# 本地验证

`bash scripts/verify.sh` 检查 Mock 健康进程、包测试、未签名报告、桌面重复点击、Harness 文本流和取消，并接着检查本机平台的登录、撤销和额度。失败时返回非零。

只跑平台：`bash scripts/start-platform.sh`、`bash scripts/stop-platform.sh`、`bash scripts/verify-p1.sh`。验证时设置 `CPCLAW_PLATFORM_SEED=fixture` 和至少 32 位的 `CPCLAW_SESSION_SECRET`。fixture 口令只用于 Mock，不能当作生产账号。

```bash
cp .env.example .env
bash scripts/start.sh
bash scripts/verify.sh
bash scripts/stop.sh
```

`AI_MOCK_MODE` 只有精确值 `true` 能通过。`docker`、`cloud` 会失败退出。结果写到本机 `~/Library/Application Support/CPclaw/evidence/p0-02a-last.json`。

未执行项不能当成通过：签名安装包、外部身份组件、真实 MiniMax 联调。MiniMax 文本记录在 `~/Library/Application Support/CPclaw/evidence/p0-04-last.json`。P1 本机 Mock 记录在 `p1-last.json`。P0 和 P1 整体仍待验收。
