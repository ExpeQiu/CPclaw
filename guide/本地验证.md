# 本地验证

`bash scripts/verify.sh` 检查 Mock 健康进程、包测试、未签名报告、桌面重复点击、Harness 文本流和取消，并接着检查本机平台的登录、撤销和额度。失败时返回非零。

只跑平台：`bash scripts/start-platform.sh`、`bash scripts/stop-platform.sh`、`bash scripts/verify-p1.sh`。P2–P5：`bash scripts/verify-p2.sh`、`bash scripts/verify-p3.sh`、`bash scripts/verify-p4.sh`、`bash scripts/verify-p5.sh`。验证时设置 `CPCLAW_PLATFORM_SEED=fixture` 和至少 32 位的 `CPCLAW_SESSION_SECRET`。fixture 口令只用于 Mock，不能当作生产账号。

```bash
cp .env.example .env
bash scripts/start.sh
bash scripts/verify.sh
bash scripts/stop.sh
```

`AI_MOCK_MODE` 只有精确值 `true` 能通过。`start.sh --target docker|cloud` 仍会失败退出（P0 本机健康进程合同）。结果写到本机 `~/Library/Application Support/CPclaw/evidence/p0-02a-last.json`。

## 远程平台联调（验证用）

控制面 Docker 部署到验证主机 `47.113.225.93`；本机跑执行面与 verify。不等于正式生产选型，也不等于 P0–P5 正式通过。

**防火墙（强制）**：公网 + fixture 口令不可裸奔。部署前须把 `${REMOTE}:3928` 限制为**本机出口 IP**，并设置 `CPCLAW_FIREWALL_ACK=yes`。脚本在未确认时拒绝部署。可再设 `CPCLAW_FIREWALL_SOURCE_IP=<本机出口IPv4>`，由部署脚本写远端 iptables 白名单；**云安全组仍须另行收紧**。

```bash
# 本机 .env（勿入库）
AI_MOCK_MODE=true
CPCLAW_SESSION_SECRET=<至少32位>
CPCLAW_FIREWALL_ACK=yes
CPCLAW_FIREWALL_SOURCE_IP=<本机出口IPv4>
CPCLAW_REMOTE_HOST=47.113.225.93
CPCLAW_PLATFORM_URL=http://47.113.225.93:3928

# 远端部署（需 SSH、远端 Docker）
bash scripts/deploy-platform-remote.sh

# 本机冒烟 + P1–P5（P1 打远程；P2–P5 包测并预检远程健康）
bash scripts/verify-platform-remote.sh
bash scripts/verify-remote.sh

# 停止远端
bash scripts/stop-platform-remote.sh
```

制品与编排在 `deploy/platform/`。容器内 `CPCLAW_LISTEN_HOST=0.0.0.0`、`CPCLAW_DATA_DIR=/data`。本机未设置 `CPCLAW_PLATFORM_URL` 时，`verify-p1` 仍启本机环回平台。

未执行项不能当成通过：签名安装包、外部身份组件、真实 MiniMax 联调、正式知识样本、CLI/MCP、飞书/企微正式应用、试点达标。MiniMax 文本记录在 `~/Library/Application Support/CPclaw/evidence/p0-04-last.json`。P1–P5 本机 Mock 分别在 `p1-last.json` … `p5-last.json`；远程冒烟在 `platform-remote-last.json`。各阶段整体仍待验收。移交说明见 `guide/用户指南.md`、`guide/管理员手册.md`、`guide/故障恢复.md`、`guide/已知限制与验收索引.md`。
