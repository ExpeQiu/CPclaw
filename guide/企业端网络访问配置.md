# 企业端网络访问配置

网络来源由服务器运维配置管理，桌面端无需升级。支持两种 IPv4 模式：`all` 允许所有来源，`allowlist` 仅允许指定 IP 或网段。两种模式都保留员工编号、口令及业务接口令牌验证。

## 设置方式

允许所有 IPv4 来源（当前设置）：

```bash
CPCLAW_FIREWALL_MODE=all CPCLAW_FIREWALL_ACK=yes \
  bash scripts/configure-platform-network.sh
```

仅允许指定 IP 或网段：

```bash
CPCLAW_FIREWALL_MODE=allowlist \
CPCLAW_FIREWALL_CIDRS=192.0.2.1,198.51.100.0/24 \
CPCLAW_FIREWALL_ACK=yes bash scripts/configure-platform-network.sh
```

使用 `--check` 仅校验配置，不连接服务器。也可将上述变量写入本机私有 `.env`。旧变量 `CPCLAW_FIREWALL_SOURCE_IP` 继续兼容。

配置脚本只调整 TCP 3928 的 CPclaw 规则，不重建平台。规则保存到远端 `/opt/cpclaw-platform/network-policy.sh`，通过 `cpclaw-network.service` 在 Docker 启动后应用。部署脚本优先使用显式 `CPCLAW_FIREWALL_MODE`；未指定时沿用服务器保存的策略，避免旧单 IP 配置覆盖当前 all。首次无保存策略时兼容旧单 IP 变量。

云安全组仍是独立网络边界；若主机规则已允许但客户端仍超时，还需检查云安全组和客户端网络。`all` 表示所有 IPv4 来源，不包含 IPv6 地址入口。
