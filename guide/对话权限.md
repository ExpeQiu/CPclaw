# 对话权限与 Harness 自主执行

输入框旁的权限菜单控制当前对话的实际工具执行：

| 模式 | 自动执行 | 询问时机 |
|---|---|---|
| 请求批准（默认） | 服务目录等本地工具元信息 | 每次业务读取、文件修改、终端命令或服务调用前询问 |
| 帮我批准 | 当前项目内的文件读取、已知即梦只读接口、MCP 目录及明确声明只读且非破坏性的工具 | 外部文件读取、写入、未知命令与工具；可以另行授权当前任务或对话内的同一服务 |
| 完全访问权限 | 本机文件读写、通用终端命令、已配置 CLI/MCP、网络操作及非敏感原生页操作 | 内置即梦通道超出已批准的积分额度、重新授权，以及原生页登录/支付（含密码框） |

完全访问使用本机进程实际拥有的操作系统权限，不受当前项目目录限制；不能突破 macOS 权限。用户通过通用终端直接运行的第三方程序按其自身权限与计费规则执行，宿主不能保证给任意终端命令施加即梦专用积分额度。

权限由宿主按账号与对话保存于内存，模型不能传入「已批准」字段。切换到其他对话不继承权限，返回原对话保留所选模式；退出账号清除该账号的模式，退出应用后恢复默认。切换权限或撤销会中止正在执行的工具，使旧任务后续工具调用失效；重新发起任务使用新权限。当前正在进行的外部任务可能已产生部分副作用，停止后先查询现状。

## 授权范围与对话权限的关系

对话权限是**是否需要询问**的开关；授权范围是**一次批准覆盖多大**的选择。两者相互独立，授权范围以弹窗内的用户选择为准，不受对话权限模式限制。

| 授权范围 | 覆盖范围 | 失效时机 |
|---|---|---|
| 本次任务 · 一次授权完整操作 | 该服务在本任务内的全部工具与终端指令 | 新任务重新确认 |
| 本次对话 · 此服务 | 该服务在本对话内、跨任务的后续指令 | 切换账号或对话、撤销、退出应用 |
| 仅当前操作 | 只放行详情中列出的这一次 | 下一次操作再次询问 |

因此在默认的「请求批准」模式下，仍可在弹窗里选择「本次任务」或「本次对话」，一次授权覆盖整段任务；「帮我批准」与「完全访问权限」只是让符合特征的操作免于弹窗，不改变弹窗内可选的范围。弹窗会显示当前对话权限，便于区分两层含义。

「本次任务」需要任务标识，「本次对话」需要账号与对话标识；缺少对应标识时该选项不可选，只能单次授权。授权绑定服务地址、本机程序真实路径和内容指纹，不扩展到其他服务或被替换的程序。

## Harness 能自主完成的工作

Harness 在同一个工具循环中依据本轮服务目录选择服务、发现能力、执行任务、分析失败并验证结果。`service_action` 请求可指定 `serviceId` 切换本轮已提供的服务。未指定具体服务时使用本机文件与终端入口，不强制弹出服务选择框。

本机工具 `local-terminal` 提供 `discover`、`read_file`、`write_file` 与 `terminal`。目录默认为当前项目，未关联项目时为用户主目录；工具可显式指定目录与文件路径。自动模式只放行可确定的项目内读取；通用 shell 命令按未知操作处理，需要批准或完全访问模式。写文件后校验内容，终端返回退出码、输出和错误，单次命令最多运行五分钟。取消和超时会停止当前终端进程组。

原生页工具 `browser-page` 提供 `discover`、`open`、`snapshot` 与按可访问树 `ref` 的 `click` / `type` / `scroll` / `press`。`snapshot` 在自动模式下可放行；点击与输入服从当前权限模式。登录、支付相关 URL/控件或密码输入一律 `forceApproval`，即使完全访问也会询问。详见 [ADR-003](../docs/decisions/ADR-003-原生页面ComputerUse.md)。

用户仍通过选择服务、权限模式和额度决定范围；Harness 负责具体步骤，不要求用户逐条指挥。原有工具回执、任务记录、积分批准和结果验证继续保留。

## 验证

- `node --test apps/desktop/test/*.test.mjs`：模式隔离、真实文件和终端、原生页敏感确认、拒绝、降权、超时与路由，含「请求批准」模式下任务级与对话级授权范围可选、任务授权在任务内复用、单次授权不覆盖后续。
- `pnpm test:desktop:permissions`：真实 IPC、权限菜单、跨目录写入、终端输出、弹窗次数、撤销与账号隔离，含弹窗默认选项、范围可选性与上下文显示。
- `pnpm --filter @cpclaw/desktop exec electron ../../scripts/verify-service-consent.mjs`：任务授权、额度、拒绝与撤销回归。
- `pnpm --filter @cpclaw/desktop exec electron ../../scripts/verify-extension-host.mjs`：原生页隔离、snapshot refs、登录/支付强制确认。
