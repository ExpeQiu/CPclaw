0.0.40 增加任务快照、内核接收检查点、分段文档草稿，以及普通聊天和 Harness 模型请求的有限重试。

## 发生中断后

可以点击重试；对于已有检查点的最后一条失败任务，也可以直接输入「继续」「继续原任务」「继续当前任务」「接着做」或「恢复任务」。系统沿用原输入、项目、已确定的交付路线和资料快照。需要更换分析对象、项目或服务配置时，应新建请求明确范围。

针对“梳理/分析现有项目技术架构或源码”的请求，如果没有明确仓库链接、本机路径、所选源码资料或关联的源码项目，会先询问分析对象，不直接扫描用户主目录或猜测同名仓库。

## 内核检查点

任务区分「准备发送」「已持久接收」「工具已执行」和「成果已交付」。内核持久化接收回执到达时立即更新会话游标，不再等待整轮成功后才更新。模型失败后的续接使用同一内核会话，补入续接指令，复用该任务已有回执。

相同服务和相同参数的已成功工具调用通过规范化指纹匹配，返回原回执而不重复执行。指纹不保存参数正文；只复用本任务回执，不跨聊天或其他任务复用。语义相同但参数不同的操作不能仅凭指纹自动判定为同一次操作，仍由原任务范围、模型续接指令与宿主授权共同约束。

如果发送中断且尚未确认内核接收状态，或工具操作没有取得回执，不盲目重发。项目目录失效时停止，不退回用户主目录。已有旧任务缺少这些检查点时继续沿用原来的恢复保护，不编造接收证据。

## 长文档

新客户端按段交付，模型被要求每段约 1200 字，未完的段落保存为本机草稿，最后一段完成后再合并、校验并发布文档。单轮最多推进 8 段，整体仍受 128000 字符上限约束；达到分段上限后保留草稿，可继续原请求。

遇到模型 `length` 截断时，仅在能够安全识别文件名、目标与正文前缀时保存为草稿；不把不完整 JSON 当作已完成交付。续接携带已有草稿尾部和长度，续接指令要求只生成新段落。改名、改变修订目标、重复片段事件或越界交付会被拒绝。草稿在应用重启后保留；最终发布成功后清除草稿检查点。

任务快照和草稿保存在本机聊天数据库，属于任务数据，不进入诊断日志。发送模型请求时仍会携带完成任务所需的上下文。

云端按客户端版本启用分段协议；0.0.39 及旧版仍使用完整文档交付协议。

## 模型临时错误

只对明确收到的 HTTP 429、502、503、504、529 响应进行有限重试，最多 3 次 HTTP 尝试，沿用同一个模型请求内容。遵循 Retry-After；等待超过 10 秒或超过当前超时预算时交回失败，不提前重试。没有等待提示时采用退避和抖动。

已经返回 HTTP 200 后发生的流中断不会整段重放；工具步骤也不会因模型 HTTP 重试重新执行。每次 HTTP 尝试的状态与等待时间进入诊断快照。

## 0.0.41：Harness 最终答复与架构资料收集

原生 Harness 的最终文字达到输出上限时，新客户端保存可见正文检查点，并转入文档分段交付。交付失败后重启、重试仍从该草稿继续，不重新进入内核搜集资料。工具参数截断不能当作可续写正文。云端对支持此协议的客户端返回明确的 `MODEL_OUTPUT_LIMIT`（HTTP 422），旧客户端保留原 HTTP 状态。正文只进入任务草稿和响应，不写入诊断日志；诊断保留实际文字数量、结束原因与已知用量。

架构、源码研究进入资料收集阶段后，读取六份文件回执，或至少三份且总量达到一万字符并含源码文件，便转入交付；工具回执达到十二条也会停止继续采集。阈值是采集预算，不代表资料完整或结论已核验。交付只使用已有回执摘录，必须注明文件、第三方属性及未覆盖项。没有可用源码回执时先说明缺失来源，不生成无依据的架构成果。

对未指定来源的架构检索，宿主阻止直接克隆猜测仓库和常见的用户主目录 `find` 扫描命令，返回 `SOURCE_SCOPE_REQUIRED`。这是任务范围约束；通用终端授权仍由原有权限流程处理。

## 后续源码修复：公开检索与最终交付（尚未发布）

公开文章、远程 README、仓库搜索结果等网络回执可以作为研究资料，不再只接受本机源码文件。达到采集预算时，已有检索结果用于说明候选与未覆盖范围；不能因为没有本机源码而丢弃这些结果。命令行工具发现和版本检查不算网页证据；网页内容也不等于已核验源码。引用链接由已有请求或回执提取，不重新发起检索。

紧接架构任务的明确补充检索指令（例如“你可以去互联网检索相关信息”）保留上一用户请求的研究主题、采集预算和成果标题。不同任务之间不自动继承此主题。

有草稿或已经锁定文档路线时，模型关闭自适应思考，专注分段输出；最终交付不再携带执行服务路由提示，资料不足之处写明限制。初始聊天和服务选择保留原路由策略。诊断增加 `reasoningChars` 数量，与正文和工具参数长度共同判断卡在思考还是交付阶段；不保存推理原文。
