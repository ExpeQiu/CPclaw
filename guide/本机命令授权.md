# 本机命令执行授权

CPclaw 在当前电脑执行已配置 CLI，无需打开系统终端窗口。用户直接在对话中提出任务；AI 发起的操作也必须经过本机宿主授权，不能通过对话文字、生成文档或“已批准”参数绕过。

## 如何授权

弹窗列出用途、实际程序路径、参数、工作目录或 MCP 服务地址和操作内容。点击“授权并执行”才执行当前操作；“拒绝”、关闭窗口或 Escape 都表示拒绝。普通服务操作仅允许本次调用，不授予永久 shell 权限。

即梦能力发现会集中读取版本、schema、登录状态、账号及当前画布。后续操作依照真实能力执行。生成积分另有确认弹窗，列出实际逐项报价、总上限、目标画布与节点；拒绝时不批准积分、不提交生成。批准凭据只留在宿主内存中。

拓展中的固定“检查连接”仍支持“仅本次”或“当前对话内相同即梦只读检查”，该复选框只覆盖弹窗中列出的原有检查命令，不授权创作、其他程序或 SaaS 调用。

## 有效范围与撤销

切换账号、聊天、进入早期任务或退出应用后，未完成授权和后续命令会停止。固定只读检查的对话授权仅在主进程内存中保存，程序、参数或目录改变需要重新确认，右侧提供撤销按钮。

“停止生成”会停止当前本机命令或等待中的授权。若远端任务已经受理，停止本机等待不等于取消远端生成；必须用原提交编号查询状态，不能换编号自动重试。宿主保存恢复所需的公开身份，不保存积分 token、访问凭据或临时签名地址。

## 与系统及服务权限的关系

这是 CPclaw 对本机执行或服务调用的确认，不等于 macOS 管理员、受保护目录、钥匙串或 SaaS 账号权限。系统和应用要求的登录仍按其官方流程完成。即梦设备授权由宿主保管设备引用并打开官方授权页；用户在浏览器完成后继续原任务，不反复发起新登录。

本轮未开放任意 shell 拼接、自动安装、提权和破坏性即梦操作。其他已配置 CLI 的实际行为由该程序决定，授权弹窗会显示完整程序与参数；不把它们推断为只读。
